# Developer Certificate of Origin / 开发者原创声明

本文件是 **DCO（Developer Certificate of Origin）1.1** 官方原文，适用于 **PhysChem-DigitizerP** 项目的全部贡献。
本项目采用 DCO 机制，**无需签署任何单独的贡献者协议**：贡献者只需在其每一次提交中附带一行
`Signed-off-by: 姓名 <邮箱>` 签署声明，即视为已确认并同意下述全部内容。

签署方式与提交规范详见 [CONTRIBUTING.md](CONTRIBUTING.md)。

### 签署方式

在提交信息末尾附上一行：

```
Signed-off-by: 姓名 <邮箱>
```

使用 `git commit -s`（或 `git commit --signoff`）可自动生成该行。姓名与邮箱须与
`git config user.name` / `git config user.email` 一致，且与提交者身份真实对应。
