# 电压传感器

三种采集方案共用上位机模块 `voltage_sensor.py`：ESP32 内置 ADC、HX711 24 位 ADC、ADS1115 16 位 I2C ADC。支持 kV/V/mV 单位切换、去皮、分压比/放大比设置，参数保存在 `sensor_config.json`。

## 1.方案对比

| 特性 | ESP32 内置 | HX711 | ADS1115 |
|------|-----------|-------|---------|
| 分辨率 | 12 位（默认） | 24 位有符号 | 16 位有符号 |
| 接口 | GPIO 直读 | HX711 协议（DOUT/SCK） | I2C |
| 量程 | 0~3.3V | ±39mV（A）/ ±156mV（B） | ±6.144V ~ ±0.256V（6档 PGA） |
| 成本 | 最低 | 中 | 中 |

## 2.接线

### 2.1.方式一：ESP32 内置 ADC

```
ESP32-S3          被测信号
──────────        ────────
GPIO1       ←     信号输出（0-3.3V）
GND         ←     GND（共地）
```

固件 `ESP32_Voltage_Sensor.ino`：12 位、11dB 衰减（0-3.3V 量程）、采样间隔 100ms。

> 被测电压超过 3.3V 必须加分压电路，否则可能损坏 ADC。

### 2.2.方式二：HX711 24 位

```
ESP32-S3          HX711            被测信号
──────────        ──────────       ────────
GPIO4       ←     DOUT        ←    A+/A-（差分）
GPIO5       →     SCK
3.3V        →     VCC
GND         →     GND
```

固件 `HX711_Voltage.ino`：通道 A（增益 128，±39mV）或通道 B（增益 32，±156mV），AVDD 取 5V 换算。

### 2.3.方式三：ADS1115 16 位（I2C）

```
ESP32-S3          ADS1115          被测信号
──────────        ──────────       ────────
GPIO21 (SDA) ←    SDA         ←    AIN0~AIN3
GPIO22 (SCL) →    SCL
3.3V        →     VDD
GND         →     GND
GND         →     ADDR（地址 0x48）
```

固件 `ADS1115_Voltage.ino`，依赖 [Adafruit ADS1X15](https://github.com/adafruit/Adafruit_ADS1X15) 库。默认 PGA = ±6.144V（`GAIN_TWOTHIRDS`），数据率 128 SPS。

**PGA 档位（在固件中通过 `PGA_RANGE` 选择，需与上位机设置一致）：**

| PGA 设置 | 量程 | LSB 分辨率 |
|----------|------|-----------|
| `GAIN_TWOTHIRDS`（固件默认） | ±6.144V | 187.5µV |
| `GAIN_ONE` | ±4.096V | 125µV |
| `GAIN_TWO` | ±2.048V | 62.5µV |
| `GAIN_FOUR` | ±1.024V | 31.25µV |
| `GAIN_EIGHT` | ±0.512V | 15.625µV |
| `GAIN_SIXTEEN` | ±0.256V | 7.8125µV |

**输入通道（固件中 `MUX_CHANNEL` 选择）：**

| 通道 | 类型 |
|------|------|
| `ADS_PIN_AIN0` ~ `ADS_PIN_AIN3` | 单端（相对 GND，只能测 0 ~ +FSR） |
| `ADS_PIN_DIFF_01` / `ADS_PIN_DIFF_23` | 差分（可测负值） |

> 同一时间只启用一个通道；切换通道需改固件重新烧录，不支持运行时切换。上位机的"通道"下拉框只是显示标识，实际通道由固件决定。

## 4.数据格式与换算

三种固件统一输出：`时间戳(ms),ADC原始值`

```
0,1234        ← ESP32 内置（12位，0~4095）
100,1355
```

**ESP32 内置：** 固件输出 0~4095 无符号值（11dB 衰减，对应 0~3.3V），换算 `电压 = adc / 4095 × 3.3`。只能测正电压；要测负电压需在输入端加 VCC/2 偏置电路，把信号抬到 0V 以上。

**HX711（有符号）：** `电压 = adc / 8388608 × (AVDD / Gain)`，通道 A 增益 128、通道 B 增益 32。

**ADS1115（有符号补码）：** `电压 = adc / 32768 × FSR`，FSR 由 PGA 决定。

上位机内置三种模式的换算，选择对应 ADC 位数（8~24）和模式开关即可。

## 5.使用步骤

1. 选择方案并烧录对应固件
2. 按上文接线
3. 运行 `main.py`，进入电压传感器模块
4. 配置 ADC 位数 / HX711 / ADS1115 模式及参数（PGA、通道、AVDD、分压比、放大比）
5. 连接串口，开始采集
6. 数据可存为 CSV（含时间、原始 ADC、各级电压）

## 6.常见问题

**ADC 读数跳动大**
- 检查共地
- 信号线并联 0.1µF 电容
- 远离电机、开关电源等干扰源

**HX711 读数为 0**
- DOUT/SCK 接线错误
- 上电后等待 500ms 稳定
- AVDD 设置与实际供电不符（默认 5V）

**ADS1115 找不到设备**
- SDA=GPIO21、SCL=GPIO22
- ADDR 必须接 GND（地址 0x48）
- 未安装 Adafruit ADS1X15 库

**单端读不到负值**
- 单端模式 AINN 内部接 GND，量程 0 ~ +FSR
- 测负值用差分模式（`ADS_PIN_DIFF_01` 等）
