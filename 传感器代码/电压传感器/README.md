# 电压传感器

三种 ADC 方案任选：ESP32 内置 ADC（12 位）、HX711（24 位）、ADS1115（16 位 I2C）。上位机 `voltage_sensor.py`（主类 `VoltageSensorWidget`，侧边栏图标 `V`）支持 ADC 位数、分压比、放大倍数、去皮与单位切换（kV / V / mV）。

## 1.方案对比

| 特性 | ESP32 内置 | HX711 | ADS1115 |
|------|-----------|-------|---------|
| 分辨率 | 12 位（默认） | 24 位有符号 | 16 位有符号 |
| 接口 | GPIO 直读 | HX711 协议（DOUT/SCK） | I2C |
| 量程 | 0~3.3V | ±39mV（A）/ ±156mV（B） | ±6.144V ~ ±0.256V（6档 PGA） |
| 成本 | 最低 | 中 | 中 |
| 适合测什么 | 量程大的信号 | 极微弱差分信号（热电偶、毫伏级） | 中等精度、要求低噪声 |

## 2.接线

### 2.1.方式一：ESP32 内置 ADC

```
ESP32-S3          被测信号
──────────        ────────
GPIO1       ←     信号输出（0-3.3V）
GND         ←     GND（共地）
```

- 固件 `ESP32_Voltage_Sensor.ino`：`ADC_PIN 1`、12 位、11dB 衰减（0-3.3V 量程）、采样间隔 100ms
- 输出 0~4095 无符号值，只能测正电压
- 要测负电压，得在输入端加 VCC/2 偏置电路把信号抬到 0V 以上，再扣掉偏置

> 被测电压超过 3.3V 必须加分压电路，否则可能损坏 ADC！！！

### 2.2.方式二：HX711 24 位

```
ESP32-S3          HX711            被测信号
──────────        ──────────       ────────
GPIO4       ←     DOUT        ←    A+/A-（差分）
GPIO5       →     SCK
3.3V        →     VCC
GND         →     GND
```

- 固件 `HX711_Voltage.ino`：`HX711_DOUT_PIN 4` / `HX711_SCK_PIN 5`，采样间隔 100ms
- 固件固定用通道 B（增益 32，量程 ±156mV），启动信息里会打印 `- Channel: B (Gain 32, +-156mV)`
- AVDD 默认按 5V 换算（HX711 模块 VCC 常接 5V）

### 2.3.方式三：ADS1115 16 位（I2C）

```
ESP32-S3          ADS1115          被测信号
──────────        ──────────       ────────
GPIO21 (SDA) ←    SDA         ←    AIN0~AIN3
GPIO22 (SCL) →    SCL
3.3V        →     VDD
GND         →     GND
GND         →     ADDR（地址 0x48）
```

固件 `ADS1115_Voltage.ino`，依赖 [Adafruit ADS1X15](https://github.com/adafruit/Adafruit_ADS1X15) 库。I2C 引脚 `I2C_SDA_PIN 21` / `I2C_SCL_PIN 22`，数据率 128 SPS，采样间隔 100ms。初始化失败时固件打印 `ERROR: ADS1115 not found, check wiring/address`。

PGA 档位在固件里通过 `PGA_RANGE` 选，要和上位机设置一致：

| PGA 设置 | 量程 | LSB 分辨率 |
|----------|------|-----------|
| `GAIN_TWOTHIRDS`（固件默认） | ±6.144V | 187.5µV |
| `GAIN_ONE` | ±4.096V | 125µV |
| `GAIN_TWO` | ±2.048V | 62.5µV |
| `GAIN_FOUR` | ±1.024V | 31.25µV |
| `GAIN_EIGHT` | ±0.512V | 15.625µV |
| `GAIN_SIXTEEN` | ±0.256V | 7.8125µV |

输入通道在固件里通过 `MUX_CHANNEL` 选，默认 `ADS_PIN_AIN0`：

| 通道 | 类型 |
|------|------|
| `ADS_PIN_AIN0` ~ `ADS_PIN_AIN3` | 单端（相对 GND，只能测 0 ~ +FSR） |
| `ADS_PIN_DIFF_01` / `ADS_PIN_DIFF_23` | 差分（可测负值） |

同一时间只启用一个通道，切换通道要改固件重新烧录，不支持运行时切换。上位机的"通道"下拉框只是显示标识，实际通道由固件决定。

> ⚠️ **默认值不一致的坑**：固件默认 `PGA_RANGE = GAIN_TWOTHIRDS`（±6.144V），上位机 ADS1115 模式的 PGA 下拉默认是 **±2.048V**。用默认固件时，必须把上位机下拉手动改成「±6.144V」，否则量程按 ±2.048V 换算，读数会差 3 倍。

## 4.固件与数据格式

三种固件统一输出 `时间戳(ms),ADC原始值`，波特率 115200，启动时打印一行 `START`。

```
0,1234        ← ESP32 内置（12位，0~4095）
100,1355
```

| 固件 | ADC 值形态 | 引脚 |
|------|-----------|------|
| `ESP32_Voltage_Sensor.ino` | 无符号 0~4095 | GPIO1 |
| `HX711_Voltage.ino` | 有符号 −8388608~+8388607 | GPIO4(DOUT) / GPIO5(SCK) |
| `ADS1115_Voltage.ino` | 有符号 −32768~+32767 | GPIO21(SDA) / GPIO22(SCL) |

这三种固件不要同时烧在一块板上混用。需要同时测电压和电流，用 `电学综合/` 的一体固件。

## 5.换算原理

上位机分两步把 ADC 值换算成"实际被测电压"。

### 5.1.第一步：ADC 值 → ADC 端电压

三种模式各有公式，全部按有符号处理（0 对应 0V，负值对应负电压）：

| 模式 | 公式 |
|------|------|
| 普通 ADC（内置等） | `V_adc = adc / max_adc × 3.3`，其中 `max_adc = 2^N − 1`（12 位 → 4095） |
| HX711 | `V_adc = adc / 8388608 × (AVDD / Gain)`，Gain：通道A=128、通道B=32 |
| ADS1115 | `V_adc = adc / 32768 × FSR`，FSR 由 PGA 决定 |

- ESP32 内置固件输出的是 0~4095 无符号值，映射到 0~+3.3V，与"有符号"处理不冲突
- HX711 的参考电压不是 3.3V，而是 `AVDD / Gain`（默认 5V/32 = 156.25mV，即满量程 ±156mV）
- ADS1115 的 FSR 就是 PGA 量程（如 ±6.144V），分辨率 187.5µV

### 5.2.第二步：还原分压与放大

```
实际电压 = V_adc × 分压比 ÷ 放大倍数
（启用去皮时）实际电压 −= 去皮偏移
```

界面上两个参数：

| 参数 | 含义 | 范围 | 默认 |
|------|------|------|------|
| 分压比 (R1+R2)/R2 | 还原分压前的电压；接了分压电路才 >1 | 1.0 ~ 1000.0 | 1.0 |
| 放大倍数 | 还原放大前的信号；接了运放才 >1 | 0.01 ~ 1000.0 | 1.0 |

界面会实时显示「实际量程: ±VREF × 分压比 ÷ 放大倍数」，用来核对量程是否覆盖你的被测信号。

例：分压比 2.0、放大倍数 1.0 时，ADC 端每 1V 对应实际被测电压 2V，12 位时实际量程约 ±6.6V。

## 6.上位机使用

### 6.1.连接方式

下拉框有三项：**有线串口 / BLE蓝牙 / 模拟器**。

本目录三个固件都只走 USB 串口，不含 BLE 广播。要无线连接得自己加 NUS（Nordic UART Service，`6E400001-B5A3-F393-E0A9-E50E24DCCA9E`）骨架，`超声波位移传感器/csbwithbt.ino` 可以拿来参考。没装 `bleak` 时该项灰显并标注「（未安装bleak）」；没装 pyserial 时自动切到模拟器模式。

### 6.2.参数配置（按 ADC 位数联动）

| 控件 | 说明 |
|------|------|
| ADC 位数 | 8/10/12/14/16/18/20/22/24 位，下拉项直接标注适用的硬件（12 位 ESP32内置、16 位 ADS1115等、24 位 HX711等） |
| 参考电压 | 固定 3.3V（普通 ADC 模式用） |
| HX711 模式开关 | 仅当 ADC 位数 = 24 时出现；开启后按 AVDD/Gain 换算 |
| ├ AVDD | 2.7~5.5V，默认 5.0V，步进 0.1V |
| └ 通道 | 默认 `B (增益 32, ±156mV)`，与固件默认一致；选 A 则增益 128、量程 ±39mV |
| ADS1115 模式开关 | 仅当 ADC 位数 = 16 时出现；开启后按 PGA 换算 |
| ├ PGA 量程 | 6 档，必须与固件 `PGA_RANGE` 一致（默认固件是 ±6.144V，见 2.3 的警告） |
| └ 通道 | AIN0~AIN3 / AIN0-AIN1 / AIN2-AIN3，仅作标识，实际由固件决定 |
| 分压比 / 放大倍数 | 见第 5.2 节 |
| 单位 | 千伏 (kV) / 伏 (V) / 毫伏 (mV) |

切换 ADC 位数会自动关掉不适用的模式开关（比如从 24 位切走就关掉 HX711 模式），免得用错公式。

### 6.3.去皮

「去皮」按钮把当前空载电压记为偏移（`tare_offset_v`），从后续测量值里扣掉，按钮变成「取消去皮」；再点一次恢复。偏移单位是伏特，和显示单位无关。适合量叠加在固定偏置上的小信号变化。

### 6.4.采样频率

内联可编辑下拉框，预设 10 / 5 / 2 / 1 / 0.5 / 0.2 Hz，也可以手动输入 0.1~10 Hz。三种固件都是 100ms（10Hz）输出，上位机只能降频。

### 6.5.操作步骤

1. 选择方案并烧录对应固件
2. 按上文接线
3. 运行 `main.py`，进入电压传感器模块
4. 配置 ADC 位数 / HX711 / ADS1115 模式及参数（PGA、通道、AVDD、分压比、放大比）
5. 连接串口，开始采集；需要时点「去皮」
6. 观察实时电压与曲线，数据可存为 CSV

### 6.6.实时数据与统计

「实时数据」卡显示当前 ADC 原始值与换算后的电压；下方统计栏有数据点、平均、最大、最小、标准差 σ（随当前单位换算）。「清除数据」把曲线、记录和统计一起清掉。

### 6.7.保存数据

点「保存数据」导出 CSV，文件名形如 `voltage_sensor_data_YYYYmmdd_HHMMSS.csv`，存在运行目录（`main.py` 所在目录）。表头随当前单位变化：

```
timestamp_s,raw_adc,voltage_v
0.000,2048,1.6500
0.100,2049,1.6508
```

| 列 | 含义 |
|----|------|
| `timestamp_s` | 相对开始采集的秒数（首点归零） |
| `raw_adc` | 固件上传的原始 ADC 值 |
| `voltage_{单位}` | 换算后的电压，单位后缀随选择变（`voltage_kv` / `voltage_v` / `voltage_mv`） |

### 6.8.AI 分析实验

图表卡右上角「AI 分析实验」进对话式 AI，每次提问都捎上当前数据。系统提示词覆盖三种 ADC 的换算公式、分压/放大还原、量化台阶与参考电压漂移、分辨率怎么评估，进 AI 窗口「设置 → 模块预置系统提示词」可以查看和修改。详见根目录 [README.md 第 6.7 节](../../README.md)。

## 7.常见问题

**读数恒为 0 / 负值**
- 检查共地：ESP32 GND 必须与被测信号 GND 相连
- HX711 差分输入接反会得到反号读数，交换 A+/A- 即可
- 普通 ADC 模式接了偏置电路却忘了扣偏置

**ADS1115 读数差 3 倍 / 无数据**
- 差 3 倍：上位机 PGA 没跟着固件改（固件默认 ±6.144V，上位机默认 ±2.048V），两边必须一致
- 无数据：固件打印 `ERROR:ADS1115 not found, check wiring/address` → 检查 SDA=21 / SCL=22、供电与 ADDR 接地（0x48）

**读数噪声大 / 跳变**
- 导线过长或未屏蔽，远离电机、继电器等干扰源
- 分压电阻精度与温漂（建议 1% 金属膜）
- 降低采样频率、多做平均能明显改善

**实际量程不对**
- 检查「分压比」「放大倍数」是否按实际电路填写（分压比 = (R1+R2)/R2）
- 用已知电压源核对一次，反推修正系数
