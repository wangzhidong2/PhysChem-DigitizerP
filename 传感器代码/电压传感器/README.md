# 电压传感器模块使用说明

## 📦 上位机模块

本目录的上位机模块为 [voltage_sensor.py](voltage_sensor.py)，识别区声明：

| 字段 | 值 |
|------|-----|
| 模块名 | 电压传感器 |
| 图标 | V |
| 类别 | physics |
| 主类 | `VoltageSensorWidget` |

支持三种采集模式：

| 模式 | ADC 位数 | 下位机输出 | 上位机换算后量程 | 适用固件 |
|------|---------|-----------|----------------|---------|
| **ESP32 内置 ADC** | 8~24 位可选（默认 12 位） | 有符号 -(2^N-1)~+(2^N-1)，如 -4095~+4095 | 有符号 -VREF~+VREF，如 -3.3V~+3.3V | [ESP32_Voltage_Sensor.ino](ESP32_Voltage_Sensor.ino) |
| **HX711 24 位** | 24 位有符号补码 | -8388608 ~ +8388607 | ±(AVDD/Gain) | [HX711_Voltage.ino](HX711_Voltage.ino) |
| **ADS1115 16 位** | 16 位有符号补码 | -32768 ~ +32767 | ±FSR（由 PGA 决定） | [ADS1115_Voltage.ino](ADS1115_Voltage.ino) |

支持 kV/V/mV 单位切换、去皮（Tare）功能、分压比/放大比设置。校准参数保存在 `sensor_config.json`。

### 三种模式对比

| 特性 | ESP32 内置 | HX711 | ADS1115 |
|------|-----------|-------|---------|
| 分辨率 | 12 位（默认） | 24 位 | 16 位 |
| 接口 | GPIO 直读 | HX711 专用协议 | I2C |
| 量程 | ±1.65V（默认，可配分压扩展） | ±156mV / ±39mV | ±6.144V ~ ±0.256V（6 档 PGA） |
| 通道 | 单路 | A/B（增益 128/32） | 4 单端 + 2 差分（MUX） |
| 适用场景 | 一般电压测量 | 微小电压/高增益 | 宽量程高精度 |
| 成本 | 最低 | 中 | 中 |

## 🔌 接线指南

### 方式一：ESP32 内置 ADC

```
ESP32-S3 开发板       外部电压源/传感器
──────────────        ──────────────────
   GPIO1         ←      信号输出（0-3.3V）
   GND           ←      GND（共地）
```

**固件**：[ESP32_Voltage_Sensor.ino](ESP32_Voltage_Sensor.ino)

```cpp
#define ADC_PIN 1              // GPIO1 (ADC1_CH0)
#define SAMPLE_INTERVAL 100    // 100ms (10Hz)
// 下位机输出有符号 ADC 值 -4095~+4095（0 对应 0V）
// 上位机换算公式：voltage = (adc / 4095) × VREF
```

> ⚠️ 被测电压必须在 **0-3.3V** 范围内，超过可能损坏 ADC。高压测量请加分压电阻。
>
> 💡 测量负电压或交流电时，需在信号输入端加 **VCC/2 偏置电路**（两个等值电阻分压），使 0V 输入对应 ADC 中点 0。下位机输出有符号值，上位机按上述公式换算为 -3.3V~+3.3V。

### 方式二：HX711 24 位 ADC

```
ESP32-S3              HX711 模块          被测信号
──────────────        ───────────         ─────────
   GPIO4       ←──    DOUT          ←     A+/A-（差分）
   GPIO5       ──→    SCK
   3.3V/5V     ──→    VCC
   GND         ──→    GND
```

**固件**：[HX711_Voltage.ino](HX711_Voltage.ino)

```cpp
#define HX711_DOUT_PIN 4       // GPIO4
#define HX711_SCK_PIN  5       // GPIO5
// 通道 B（增益 32，±156mV），通道 A（增益 128，±39mV）
```

| 通道 | 增益 | 满量程差分电压（AVDD=5V） |
|------|------|--------------------------|
| A | 128 | ±39mV |
| B | 32 | ±156mV |

### 方式三：ADS1115 16 位 I2C ADC

```
ESP32-S3              ADS1115 模块        被测信号
──────────────        ───────────         ─────────
   GPIO21 (SDA) ←──   SDA            ←    AIN0~AIN3
   GPIO22 (SCL) ──→   SCL
   3.3V/5V     ──→    VDD
   GND         ──→    GND
   GND         ──→    ADDR（地址 0x48）
```

**固件**：[ADS1115_Voltage.ino](ADS1115_Voltage.ino)

**依赖库**：[Adafruit ADS1X15](https://github.com/adafruit/Adafruit_ADS1X15)（Arduino IDE 库管理器搜索安装）

**PGA 量程**（6 档，对应数据手册 PGA[2:0]）：

| PGA 设置 | 量程 | 分辨率（LSB） | 适用场景 |
|----------|------|--------------|----------|
| `GAIN_TWOTHIRDS` | ±6.144V | 187.5μV | 宽范围电压监测 |
| `GAIN_ONE` | ±4.096V | 125μV | 5V 系统监测 |
| `GAIN_TWO`（默认） | ±2.048V | 62.5μV | 通用精密测量 |
| `GAIN_FOUR` | ±1.024V | 31.25μV | 低电压精密 |
| `GAIN_EIGHT` | ±0.512V | 15.625μV | 传感器输出 |
| `GAIN_SIXTEEN` | ±0.256V | 7.8125μV | 微小信号 |

**输入通道**（MUX）：

| 通道 | 类型 | 说明 |
|------|------|------|
| `ADS_PIN_AIN0` | 单端 | AIN0 相对 GND |
| `ADS_PIN_AIN1` | 单端 | AIN1 相对 GND |
| `ADS_PIN_AIN2` | 单端 | AIN2 相对 GND |
| `ADS_PIN_AIN3` | 单端 | AIN3 相对 GND |
| `ADS_PIN_DIFF_01` | 差分 | AIN0 - AIN1 |
| `ADS_PIN_DIFF_23` | 差分 | AIN2 - AIN3 |

> 💡 单端测量时，AINN 内部接 GND，量程为 0 ~ +FSR（负值读不到）。差分测量才能读到负值。

#### ADS1115 通道切换步骤

ADS1115 的通道（MUX）通过固件宏定义配置，切换通道需修改固件并重新烧录：

**第 1 步：打开固件文件**

用 Arduino IDE 打开 [ADS1115_Voltage.ino](ADS1115_Voltage.ino)。

**第 2 步：定位通道配置区**

在文件中找到 `用户配置区` 的 `MUX_CHANNEL` 宏定义（约第 53~61 行）：

```cpp
// 输入通道选择（MUX）
// 单端：读取 AIN0/AIN1/AIN2/AIN3 相对 GND 的电压
// 差分：读取两通道电压差（AINP - AINN）
#define MUX_CHANNEL ADS_PIN_AIN0    // 单端 AIN0
// #define MUX_CHANNEL ADS_PIN_AIN1  // 单端 AIN1
// #define MUX_CHANNEL ADS_PIN_AIN2  // 单端 AIN2
// #define MUX_CHANNEL ADS_PIN_AIN3  // 单端 AIN3
// #define MUX_CHANNEL ADS_PIN_DIFF_01  // 差分 AIN0-AIN1
// #define MUX_CHANNEL ADS_PIN_DIFF_23  // 差分 AIN2-AIN3
```

**第 3 步：修改通道**

注释掉当前启用的行，取消注释目标通道。例如切换到 **AIN1 单端**：

```cpp
// #define MUX_CHANNEL ADS_PIN_AIN0    // 单端 AIN0  ← 注释掉
#define MUX_CHANNEL ADS_PIN_AIN1  // 单端 AIN1  ← 取消注释
// #define MUX_CHANNEL ADS_PIN_AIN2  // 单端 AIN2
// #define MUX_CHANNEL ADS_PIN_AIN3  // 单端 AIN3
// #define MUX_CHANNEL ADS_PIN_DIFF_01  // 差分 AIN0-AIN1
// #define MUX_CHANNEL ADS_PIN_DIFF_23  // 差分 AIN2-AIN3
```

又如切换到 **AIN0-AIN1 差分**（可测负值）：

```cpp
// #define MUX_CHANNEL ADS_PIN_AIN0    // 单端 AIN0
// #define MUX_CHANNEL ADS_PIN_AIN1  // 单端 AIN1
// #define MUX_CHANNEL ADS_PIN_AIN2  // 单端 AIN2
// #define MUX_CHANNEL ADS_PIN_AIN3  // 单端 AIN3
#define MUX_CHANNEL ADS_PIN_DIFF_01  // 差分 AIN0-AIN1  ← 取消注释
// #define MUX_CHANNEL ADS_PIN_DIFF_23  // 差分 AIN2-AIN3
```

**第 4 步：保存并烧录**

1. `Ctrl+S` 保存修改
2. 选择开发板：**Tools → Board → ESP32S3 Dev Module**
3. 选择端口：**Tools → Port → 对应 COM 口**
4. 点击上传按钮 `→` 烧录到 ESP32-S3

**第 5 步：上位机同步设置**

烧录完成后，在电压传感器模块界面同步通道配置：

1. ADC 位数下拉框选 **16 位**
2. 勾选 **ADS1115 模式**
3. 在 **通道** 下拉框选择与固件一致的通道（如 `AIN1` 或 `AIN0-AIN1`）
4. PGA 量程也需与固件 `PGA_RANGE` 宏一致

> ⚠️ 注意事项：
> - 同一时间只能启用一个通道（只有一个 `#define MUX_CHANNEL` 不带 `//`）
> - 单端模式（AIN0~AIN3）只能测 0 ~ +FSR，测负值必须用差分模式
> - 切换通道后需重新烧录固件，不支持运行时切换
> - 上位机通道设置仅用于显示标识，不影响实际测量通道（由固件决定）

## 💻 固件说明

### 数据输出格式

三种固件统一输出：**`时间戳(ms),ADC原始值`**

**ESP32 内置 ADC 示例**（12 位有符号，-4095~+4095）：
```
0,-12
100,35
200,-8
```

**HX711 示例**（24 位有符号）：
```
0,-1234567
100,890123
200,-2345678
```

**ADS1115 示例**（16 位有符号）：
```
0,-1234
100,5678
200,-8912
```

### 电压换算公式

#### ESP32 内置 ADC（有符号）

下位机输出有符号 ADC 值 -(2^N-1)~+(2^N-1)，0 对应 0V，量程 -VREF~+VREF：

```
voltage = (adc / max_adc) × VREF
```

其中 `max_adc = 2^N - 1`（N 为 ADC 位数），例如 12 位 → max_adc = 4095。

| ADC 值 | 12 位对应电压 |
|--------|--------------|
| -4095 | -3.3V |
| 0 | 0V |
| +4095 | +3.3V |

> 三种模式（ESP32 内置 / HX711 / ADS1115）统一采用有符号换算：下位机输出有符号值，0 对应 0V，上位机按 `adc / max × 量程` 换算。

#### HX711

```
voltage = adc / 8388608 × (AVDD / Gain)
```

- 通道 A：Gain = 128，AVDD=5V → 满量程 ±39mV
- 通道 B：Gain = 32，AVDD=5V → 满量程 ±156mV

#### ADS1115

```
voltage = adc / 32768 × FSR
```

| PGA | FSR | ADC=-32768 | ADC=0 | ADC=+32767 |
|-----|-----|-----------|-------|-----------|
| ±6.144V | 6.144 | -6.144V | 0V | +6.144V |
| ±2.048V | 2.048 | -2.048V | 0V | +2.048V |
| ±0.256V | 0.256 | -0.256V | 0V | +0.256V |

### 上位机模式切换

1. **ADC 位数下拉框**选择对应位数：
   - 12 位 → ESP32 内置
   - 16 位 → 显示 ADS1115 选项
   - 24 位 → 显示 HX711 选项
2. 勾选对应模式复选框
3. 调整模式专属参数（PGA/通道/AVDD 等）
4. 配置自动保存到 `sensor_config.json`

## 🎯 使用说明

### 操作流程

1. **选择方案**：根据精度需求选择 ESP32 内置 / HX711 / ADS1115
2. **烧录固件**：Arduino IDE 烧录对应 `.ino` 到 ESP32-S3
3. **接线**：按上方接线指南连接
4. **打开上位机**：运行 `main.py`，选择「电压传感器」
5. **配置模式**：
   - ADC 位数下拉框选对应位数
   - 勾选 HX711 / ADS1115 复选框（仅对应位数时可见）
   - 调整 PGA / 通道 / AVDD / 分压比 / 放大比
6. **连接串口**：选择 COM 口，点击「连接」
7. **开始采集**：点击「开始采集」
8. **保存数据**：点击「保存数据」导出 CSV

### 上位机功能

- 实时数据显示（ADC 原始值 + 换算电压）
- 实时曲线绘制
- 统计信息（平均值/最大值/最小值/标准差）
- CSV 数据保存
- 采样频率可调（0.2~10 Hz）
- 去皮（Tare）偏移校准
- 分压比/放大比换算
- kV/V/mV 单位切换

## ⚠️ 常见问题

### Q1: ADC 读数跳动大
- 检查接地是否良好（共地）
- 信号输入端并联 0.1μF 电容滤波
- 远离高频干扰源（电机、开关电源）
- 上位机启用多点平均

### Q2: HX711 读数为 0 或异常
- 确认 DOUT/SCK 接线正确（GPIO4/GPIO5）
- 上电后需等待 500ms（固件已处理）
- 首次读取会丢弃（通道切换）
- 检查 AVDD 电压设置（默认 5V）

### Q3: ADS1115 找不到设备
- 确认 I2C 接线（SDA=GPIO21, SCL=GPIO22）
- ADDR 必须接 GND（地址 0x48）
- 安装 Adafruit ADS1X15 库
- 用 I2C 扫描程序确认地址

### Q4: ADS1115 单端测不到负值
- 单端模式下 AINN 内部接 GND，量程 0 ~ +FSR
- 测负值需用差分模式（`ADS_PIN_DIFF_01` 等）
- 或外接 VCC/2 中点偏置电路

### Q5: 测量值偏差大
- 使用两点校准（已知电压建立线性校正）
- ADS1115 内置参考电压精度高，一般无需校准
- HX711 的 AVDD 实测后填入上位机
- 避开 ADC 量程两端（<5% 或 >95%）

### Q6: 找不到串口
- 安装 CH340/CP2102 驱动
- 更换 USB 数据线（部分充电线无数据）
- 关闭 Arduino IDE 等占用串口的程序

## 🔧 扩展建议

### 提升测量精度
1. **过采样**：多次采样取平均，有效分辨率提升 log₂(N) 位
2. **软件滤波**：移动平均 / 卡尔曼滤波
3. **硬件滤波**：RC 低通（R=1kΩ, C=0.1μF, fc≈1.6kHz）

### 扩展测量范围
1. **分压电阻**：精密电阻分压扩展至 0-12V、0-24V
2. **运放衰减器**：运放构建精确衰减电路
3. **差分测量**：ADS1115 差分模式或仪表放大器（INA219）

### 高压测量示例（0-12V 分压）

```
Vin (0-12V) ──┬── R1 (27kΩ) ──┬── Vout (→ ADC)
               │                │
              R2 (10kΩ)       GND
               │
              GND
```

分压比 = (R1+R2)/R2 = 37/10 = 3.7

上位机「分压比」填 **3.7**，实际电压 = ADC 电压 × 3.7
