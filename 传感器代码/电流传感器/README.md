# 电流传感器

ACS712 霍尔电流传感器（5A / 20A / 30A 三种量程），配 ESP32-S3 采集。上位机 `current_sensor.py`（主类 `CurrentSensorWidget`，侧边栏图标 `A`）支持量程切换、DC/AC 测量（AC 取滚动窗口 RMS）、零点校准与单位切换（A / mA）。

## 1.原理

ACS712 基于霍尔效应，被测电流从 IP+ / IP- 串联流过，输出电压：

```
Vout = VCC/2 + I × 灵敏度
```

| 型号 | 量程 | 灵敏度 |
|------|------|--------|
| ACS712ELC-05B | ±5A | 185mV/A |
| ACS712ELC-20A | ±20A | 100mV/A |
| ACS712ELC-30A | ±30A | 66mV/A |

- 零电流时输出约 VCC/2（5V 供电即约 2.5V），所以能测双向电流，正负号表示方向
- ACS712 输出最高约 4.5V，超出 ESP32 ADC 的 3.3V 量程，必须在输出与 ADC 之间加分压电路（分压比 ≈ 5/3.3 ≈ 1.515）
- 量程越大灵敏度越低，小电流用大量程会明显损失分辨率：5A 档约 2.4mA/LSB，30A 档约 6.8mA/LSB（按 12 位 ADC、1.5 分压估算）

## 2.接线

### 2.1.电流回路（串联接入）

```
电源正极 ──→ IP+   IP- ──→ 负载
```

ACS712 必须**串联**进被测回路（**不是并联**，要不你试试，试试就逝世，手动狗头:) ），IP+/IP- 方向任意，方向只影响电流正负。

### 2.2.信号接线

```
ACS712           分压电路          ESP32-S3
────────         ──────────        ────────
VCC  ←── 5V
GND  ←── GND（与 ESP32 共地）
OUT  ─── R1 (10kΩ) ─┬──→  GPIO1
                     │
                     R2 (20kΩ)
                     │
                    GND
```

电阻搭配：R1=10kΩ、R2=20kΩ → 分压比 (10+20)/20 = 1.5，4.5V 降到 3.0V。上位机"分压比"填实际值（默认 1.515）。

分压后对应关系（5A 量程示例）：

| 电流 | ACS712 输出 | 分压后 | ADC（12位） |
|------|------------|--------|-------------|
| 0A | 2.500V | 1.667V | ≈2068 |
| +1A | 2.685V | 1.790V | ≈2222 |
| +5A | 3.425V | 2.283V | ≈2834 |

## 4.固件与数据格式

固件：`ESP32_ADC_Raw_Data.ino`（ESP32-S3）

| 项 | 值 |
|----|-----|
| ADC 引脚 | GPIO1（`ADC_PIN 1`，ADC1_CH0） |
| 分辨率 | 12 位，量化 0~4095 |
| 衰减 | 11 dB（0-3.3V） |
| 采样间隔 | 100ms（`SAMPLE_INTERVAL 100`，10Hz） |
| 波特率 | 115200 |

串口输出：`时间戳(ms),ADC原始值`（0~4095），启动时打印配置信息并以 `START` 结束。

```
0,2068
100,2075
```

固件采样固定 100ms（10Hz），上位机"采样频率"只能降频。需要更高速率（比如捕捉 50Hz 交流波形）就改固件 `SAMPLE_INTERVAL` 后重新烧录。

## 5.换算原理

上位机分三步换算：

```
① ADC端电压  v_adc    = raw / max_adc × 3.3          （max_adc = 2^N − 1）
② 传感器输出 v_sensor = v_adc × 分压比                 （还原分压前的 ACS712 输出）
③ 电流       I        = (v_sensor − 零点电压) / 灵敏度
```

- 零点电压默认 VCC/2（2.5V），零点校准后会写入实测值；未校准时自动跟随 VCC/2
- 灵敏度由量程决定：5A→0.185 V/A，20A→0.100 V/A，30A→0.066 V/A

界面会显示一行「可测范围: x A ~ y A」，它由 ADC 满量程、分压比与零点共同决定，可能小于 ACS712 的标称量程（比如 12 位 ADC + 1.5 分压时，5A 档大概只能覆盖 ±1.7A 左右）。想发挥满量程，得降低分压比或换更高位数的 ADC。

## 6.校准

### 6.1.零点校准（推荐每次接线后做一次）

1. 让回路处于零电流状态（断开负载或拔掉电源，确保导线里没有电流）
2. 点「零点校准」，程序取最近 10 个采样点的 ACS712 输出电压均值作为零点电压
3. 按钮变为「取消零点」，状态栏显示「已校准 (零点 x.xxxV)」；再点一次恢复 VCC/2

零点校准消除的是器件零点偏差与温漂。不做校准时读数可能整体偏移几十到上百 mA。

### 6.2.灵敏度校准

灵敏度由所选量程的标称值决定，界面不提供微调。读数与标准表有系统性偏差时，先核对这两处：

- 量程是否与实际模块型号一致（三档灵敏度差很多）
- 分压电阻的实际比值（用万用表实测，别只信标称值）

### 6.3.配置持久化

参数写入 `sensor_config.json` 的 `current_sensor` 键：量程、VCC、零点电压、分压比、ADC 位数、测量模式、单位、AC 窗口、采样频率。

## 7.上位机使用

### 7.1.连接方式

下拉框有三项：**有线串口 / BLE蓝牙 / 模拟器**。

本目录的 `ESP32_ADC_Raw_Data.ino` 只走 USB 串口，不含 BLE 广播。要无线连接得自己加 NUS（Nordic UART Service，`6E400001-B5A3-F393-E0A9-E50E24DCCA9E`）骨架，`超声波位移传感器/csbwithbt.ino` 可以拿来参考。没装 `bleak` 时该项灰显并标注「（未安装bleak）」；没装 pyserial 时自动切到模拟器模式。

### 7.2.参数配置

| 控件 | 说明 | 默认 |
|------|------|------|
| 量程 | 5A (185mV/A) / 20A (100mV/A) / 30A (66mV/A)，下拉项带型号说明 | 5A |
| 测量类型 | 直流 DC / 交流 AC | DC |
| ADC 位数 | 8 / 10 / 12 / 14 / 16 位 | 12 位 |
| 供电 VCC | ACS712 供电电压，未校准时零点跟随 VCC/2 | 5.0V |
| 零点电压 | 零点校准自动写入，也可手动微调 | 2.5V |
| 分压比 | 还原 ACS712 原始输出，按实际电路填 | 1.515 |
| 单位 | 安培 (A) / 毫安 (mA) | A |
| AC 窗口 | 仅 AC 模式可用，RMS 滚动窗口点数 5~500 | 50 |

### 7.3.AC 模式

- 显示滚动窗口电流 RMS（有效值），窗口默认 50 点，可调 5~500
- 窗口越大越稳定、响应越慢
- 固件 10Hz 采样下 RMS 收敛较慢；精确测 50Hz 交流建议把固件采样间隔改到 5ms 左右重新烧录

### 7.4.采样频率

内联可编辑下拉框，预设 10 / 5 / 2 / 1 / 0.5 / 0.2 Hz，也可以手动输入 0.1~10 Hz。只能降频，固件 100ms 才出一条。

### 7.5.操作步骤

1. 烧录固件，按上文接线（串入回路 + 分压电路）
2. 运行 `main.py`，进入电流传感器模块
3. 配置量程（与实际模块型号一致）、分压比、测量类型（DC/AC）
4. 连接串口，开始采集
5. **零点校准**（推荐）：零电流状态下采集若干数据点后点"零点校准"，消除器件零点偏差
6. 数据可存为 CSV

### 7.6.实时数据与统计

「实时数据」卡显示当前 ADC 原始值与换算后的电流。下方统计栏 DC 模式给数据点、平均、最大、最小、标准差 σ，AC 模式给数据点、RMS、峰值、窗口点数。界面另有一行显示当前量程、灵敏度与零点电压。「清除数据」把曲线、记录和统计一起清掉。

### 7.7.保存数据

点「保存数据」导出 CSV，文件名形如 `current_sensor_data_YYYYmmdd_HHMMSS.csv`，存在运行目录（`main.py` 所在目录）。第一行是记录本次参数的注释，第二行才是表头：

```
# ACS712 量程=5A 灵敏度=0.185V/A 零点=2.5000V 分压比=1.515 模式=DC 单位=A
timestamp_s,raw_adc,v_adc,v_sensor,current_a
0.000,2068,1.665882,2.523812,0.128714
0.100,2075,1.669758,2.529744,0.160454
```

| 列 | 含义 |
|----|------|
| `timestamp_s` | 相对开始采集的秒数（首点归零） |
| `raw_adc` | 固件上传的原始 ADC 值 |
| `v_adc` | ADC 端电压（分压前） |
| `v_sensor` | 还原后的 ACS712 输出电压 |
| `current_{单位}` | 换算电流，后缀随单位变（`current_a` / `current_ma`） |

首行以 `#` 开头，用 pandas 读取时记得 `comment='#'`。

### 7.8.AI 分析实验

图表卡右上角「AI 分析实验」进对话式 AI，提问时自动带上最新数据。系统提示词从霍尔原理、三档灵敏度讲到零点漂移与分压误差，也能分析 AC 波形的峰值/RMS，在 AI 窗口「设置 → 模块预置系统提示词」里能看到并修改。详见根目录 [README.md 第 6.7 节](../../README.md)。

## 8.常见问题

**电流一直有零点偏移（空载不为 0）**
- 做一次「零点校准」（回路必须真的断开）
- 环境温度变化大时需重新校准
- 5V 供电不稳会导致 VCC/2 漂移，换稳定电源

**读数严重偏大 / 偏小**
- 量程选错：选了 30A 档去测 0.5A，灵敏度差 3 倍
- 分压比没按实际电路填（默认 1.515，实际用 10k/20k 就是 1.5）
- 零点电压被手动改过

**读数跳动大**
- 被测回路导线靠近强磁场、电机、继电器
- 共地不良或地环路
- 电源纹波大（开关电源明显）

**AC 模式 RMS 不稳**
- 增大 AC 窗口点数
- 固件 10Hz 对 50Hz 交流欠采样，改小 `SAMPLE_INTERVAL` 重新烧录

**ADC 恒为 0 或 4095**
- 检查 ACS712 VCC/GND/OUT 与分压电路接线
- 万用表测 OUT，零电流时应约 VCC/2
