# 电流传感器模块使用说明

## 📦 上位机模块

本目录的上位机模块为 [current_sensor.py](current_sensor.py)，识别区声明：

| 字段 | 值 |
|------|-----|
| 模块名 | 电流传感器 |
| 图标 | A |
| 类别 | physics |
| 主类 | `CurrentSensorWidget` |

基于 **ACS712 霍尔电流传感器**，支持：

- **三种量程**：±5A / ±20A / ±30A（对应 ACS712ELC-05B / -20A / -30A）
- **交直流测量**：DC 模式显示瞬时值；AC 模式计算滚动窗口 RMS（窗口 5~500 点可调）
- **零点校准**：一键取最近数据点平均作为零点电压，自动重算全部数据
- **A / mA 单位切换**、ADC 位数选择（8/10/12/14/16 位）
- 校准参数保存在 `sensor_config.json`

---

## ⚡ ACS712 工作原理

ACS712 基于霍尔效应，被测电流从 IP+ / IP- 流过（**串联接入回路**），输出电压与电流成线性关系：

```
Vout = VCC/2 + I × 灵敏度
```

- 供电 VCC（典型 5V），**零电流时输出 = VCC/2 ≈ 2.5V**
- 电流为正（IP+ → IP- 方向）输出升高，为负输出降低
- 输出与 VCC 成比例（ratiometric），VCC 波动会直接影响读数

| 型号 | 量程 | 灵敏度 |
|------|------|--------|
| ACS712ELC-05B | ±5A | 185mV/A |
| ACS712ELC-20A | ±20A | 100mV/A |
| ACS712ELC-30A | ±30A | 66mV/A |

> ⚠️ 由于 ACS712 输出最高约 4.5V，超出 ESP32 ADC 的 3.3V 量程，**必须在输出与 ADC 引脚之间加分压电路**（默认分压比 ≈ 5/3.3 ≈ 1.515）。

## 🔌 接线指南

### 电流回路（串联接入）

```
电源正极 ──→ IP+    IP- ──→ 负载
          （串入被测回路，接线方向任意）
```

### 信号接线（含分压电路）

```
ACS712 模块              分压电路                 ESP32-S3
────────────            ─────────                ─────────
  VCC  ←── 5V
  GND  ←── GND（与 ESP32 共地）
  OUT  ─── R1 (10kΩ) ───┬──→  GPIO1 (ADC1_CH0)
                        │
                        R2 (20kΩ)
                        │
                        GND
```

| ACS712 引脚 | 连接 | 说明 |
|------------|------|------|
| VCC | 5V | 模块供电 |
| GND | GND | 与 ESP32 **共地** |
| OUT | 分压电路 → GPIO1 | 输出 = VCC/2 + I × 灵敏度 |
| IP+ / IP- | 串入被测回路 | 内阻仅 1.2mΩ，对回路影响可忽略 |

**分压电阻计算**：

- 分压比 = (R1+R2)/R2，需将 5V 映射到 3.3V 以内 → 分压比 ≈ 1.515
- 推荐示例：R1 = 10kΩ，R2 = 20kΩ → 分压比 = 30/20 = **1.5**（4.5V → 3.0V，安全）
- 上位机「分压比」填实际值（如 1.5），默认 1.515

**分压后的电压对应表**（默认参数，5A 量程）：

| 电流 | ACS712 输出 | 分压后（÷1.5） | ADC 值（12 位） |
|------|------------|---------------|----------------|
| 0A | 2.500V | 1.667V | ≈2068（半量程） |
| +1A | 2.685V | 1.790V | ≈2222 |
| +5A | 3.425V | 2.283V | ≈2834 |
| −5A | 1.575V | 1.050V | ≈1304 |

## 💻 固件说明

**固件**：[ESP32_ADC_Raw_Data.ino](ESP32_ADC_Raw_Data.ino)

```cpp
#define ADC_PIN 1              // GPIO1 (ADC1_CH0)
#define SAMPLE_INTERVAL 100    // 100ms（10Hz，固件内固定）
// 12 位精度，11dB 衰减（0-3.3V 量程）
// 输出 0-4095 无符号 ADC 原始值，零电流对应半量程附近
```

### 数据输出格式

**`时间戳(ms),ADC原始值`**（0~4095）：

```
0,2068
100,2075
200,2061
```

### 电流换算公式（上位机自动完成）

```
① v_adc    = (raw_adc / max_adc) × 3.3        // ADC 引脚处电压
② v_sensor = v_adc × 分压比                    // 还原 ACS712 输出电压
③ current  = (v_sensor − 零点电压) / 灵敏度     // 电流（安培）
```

其中 `max_adc = 2^位数 − 1`（12 位 → 4095），零点电压默认 VCC/2 = 2.5V。

### 采样频率说明

- 固件固定 **100ms（10Hz）** 输出
- 上位机的「采样频率」下拉框只能**降频**（丢弃过密的数据点），不能超过固件速率
- 需要更高速率（如捕捉交流波形）请修改固件 `SAMPLE_INTERVAL` 后重新烧录

## 🎯 使用说明

### 操作流程

1. **烧录固件**：Arduino IDE 烧录 [ESP32_ADC_Raw_Data.ino](ESP32_ADC_Raw_Data.ino) 到 ESP32-S3
2. **接线**：按上方接线指南串入回路 + 接好分压电路
3. **打开上位机**：运行 `main.py`，选择「电流传感器」
4. **配置参数**：
   - 量程下拉框选对应型号（5A/20A/30A）
   - 确认分压比与实际电阻一致（如 10k/20k → 填 1.5）
   - 测量类型选 直流 DC / 交流 AC
5. **连接串口** → **开始采集**
6. **零点校准**（推荐，见下）
7. **保存数据**：导出 CSV（含原始 ADC / 各级电压 / 电流）

### 零点校准步骤

传感器实际零点与理论值 VCC/2 存在器件偏差（数十 mV），**测量前建议先校准**：

1. 连接并**开始采集**，确保回路处于**零电流**状态（断开负载或开关断路）
2. 等待至少 10 个数据点（校准取最近 10 点的传感器输出平均值）
3. 点击「**零点校准**」按钮 → 状态显示"已校准 (零点 x.xxxV)"，已有数据自动按新零点重算
4. 取消校准：点击「取消零点」恢复 VCC/2

> 手动修改「零点电压」输入框同样视为已校准。

### AC 模式说明

- 显示滚动窗口的电流 **RMS（有效值）**，窗口默认 50 点（可调 5~500）
- 窗口越大读数越稳定，但响应越慢
- 图表上叠加 ±RMS 橙色虚线参考线，统计栏显示 RMS 与峰值
- 固件 10Hz 采样下 RMS 统计收敛较慢；精确测量 50Hz 交流建议把固件 `SAMPLE_INTERVAL` 改小（如 5ms → 200Hz）后重新烧录

## ⚠️ 常见问题

### Q1: 零电流时读数不为 0
- 正常现象：零点电压存在器件偏差（VCC/2 ± 数十 mV）
- 执行「零点校准」即可消除

### Q2: 读数一直为 0 或不随负载变化
- 检查 IP+ / IP- 是否真正**串入**被测回路（不是并联！）
- 检查 OUT → 分压 → GPIO1 信号链路
- 确认量程下拉框与实际模块型号一致

### Q3: 读数跳动大
- ACS712 输出与 VCC 成比例，**供电必须稳定**（勿用劣质 USB 电源）
- 执行零点校准；确认与 ESP32 共地
- 上位机降低采样频率相当于降频平滑

### Q4: AC 模式 RMS 读数不稳
- 增大「AC RMS 窗口」（默认 50 点，可到 500）
- 固件采样率 10Hz 较低，统计收敛慢；需要精确 RMS/波形请提高固件采样率（见上文）

### Q5: 电流接近量程上限时读数异常
- 电流超出传感器线性量程（±5A/±20A/±30A），输出饱和
- 换更大量程的 ACS712 模块
- 注意：界面"可测范围"显示的是 ADC 量程允许的理论边界，**线性测量范围以传感器标称量程为准**

### Q6: 找不到串口
- 安装 CH340/CP2102 驱动
- 更换 USB 数据线（部分充电线无数据）
- 关闭 Arduino IDE 等占用串口的程序

## 🔧 扩展建议

1. **提高交流测量精度**：固件 `SAMPLE_INTERVAL` 改小（如 5ms），配合 AC 模式可获得更快的 RMS 收敛和波形细节
2. **小电流测量**：±5A 型号分辨率约 ±8mA（12 位 ADC + 分压后）；更小电流可用 ACS712 之后串联放大电路，或改用 INA219 等高精度方案
3. **多点平均**：上位机降低采样频率，等效于对高频噪声取平均
