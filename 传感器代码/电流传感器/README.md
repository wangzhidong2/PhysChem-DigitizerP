# 电流传感器

ACS712 霍尔电流传感器 + 分压电路，ESP32-S3 采集。上位机模块 `current_sensor.py`，支持 5A/20A/30A 量程切换、AC/DC 测量、零点校准，参数保存在 `sensor_config.json`。

## 1.原理

ACS712 基于霍尔效应，被测电流从 IP+ / IP- 串联流过，输出电压：

```
Vout = VCC/2 + I × 灵敏度
```

| 型号 | 量程 | 灵敏度 |
|------|------|--------|
| ACS712ELC-05B | ±5A | 185mV/A |
| ACS712ELC-20A | ±20A | 100mV/A |
| ACS712ELC-30A | ±30A | 66mV/A |

ACS712 输出最高约 4.5V，超出 ESP32 ADC 的 3.3V 量程，**必须在输出与 ADC 之间加分压电路**（分压比 ≈ 1.515）。

## 2.接线

### 2.1.电流回路（串联接入）

```
电源正极 ──→ IP+   IP- ──→ 负载
```

ACS712 必须**串联**进被测回路（不是并联），IP+/IP- 方向任意，方向只影响电流正负。

### 2.2.信号接线

```
ACS712           分压电路          ESP32-S3
────────         ──────────        ────────
VCC  ←── 5V
GND  ←── GND（与 ESP32 共地）
OUT  ─── R1 (10kΩ) ─┬──→  GPIO1
                     │
                     R2 (20kΩ)
                     │
                    GND
```

电阻搭配：R1=10kΩ、R2=20kΩ → 分压比 (10+20)/20 = 1.5，4.5V 降到 3.0V。上位机"分压比"填实际值（默认 1.515）。

分压后对应关系（5A 量程示例）：

| 电流 | ACS712 输出 | 分压后 | ADC（12位） |
|------|------------|--------|-------------|
| 0A | 2.500V | 1.667V | ≈2068 |
| +1A | 2.685V | 1.790V | ≈2222 |
| +5A | 3.425V | 2.283V | ≈2834 |

## 4.数据格式与换算

固件 `ESP32_ADC_Raw_Data.ino` 输出：`时间戳(ms),ADC原始值`（0~4095）

```
0,2068
100,2075
```

- 波特率 115200，12 位 ADC，11dB 衰减（0-3.3V）
- 固件采样固定 100ms（10Hz）；上位机"采样频率"只能降频，不能超过固件速率
- 需要更高速率（如捕捉 50Hz 交流波形）请改固件 `SAMPLE_INTERVAL` 后重新烧录

上位机换算流程：

```
ADC端电压  = raw / 4095 × 3.3
传感器输出 = ADC端电压 × 分压比
电流       = (传感器输出 − 零点电压) / 灵敏度
```

## 5.使用步骤

1. 烧录固件，按上文接线（串入回路 + 分压电路）
2. 运行 `main.py`，进入电流传感器模块
3. 配置量程（与实际模块型号一致）、分压比、测量类型（DC/AC）
4. 连接串口，开始采集
5. **零点校准**（推荐）：零电流状态下采集若干数据点后点"零点校准"，消除器件零点偏差
6. 数据可存为 CSV（含原始 ADC / 各级电压 / 电流）

### 5.1.AC 模式

- 显示滚动窗口电流 RMS，窗口默认 50 点（5~500 可调）
- 窗口越大越稳定、响应越慢
- 固件 10Hz 采样下 RMS 收敛较慢；精确测 50Hz 交流建议把固件采样间隔改到 5ms 左右重新烧录

## 6.常见问题

**零电流时读数不为 0**
- 正常，零点有器件偏差（VCC/2 附近几十 mV），做一次零点校准即可

**读数一直为 0**
- IP+/IP- 没有真正串联进回路
- 检查 OUT → 分压 → GPIO1 链路
- 量程下拉框与实际模块型号不一致

**读数跳动大**
- ACS712 输出随 VCC 变化，供电必须稳定
- 确认与 ESP32 共地

**电流接近量程上限时读数异常**
- 超出传感器线性量程，输出饱和
- 换更大量程的 ACS712 模块
