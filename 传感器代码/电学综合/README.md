# 电学综合：欧姆定律 + 电功率
<span style="font-size:36px;">上位机模块正在开发</span>

本目录提供两个上位机模块与**七套固件**（3 套「电压+电流」双通道一体固件 + 4 套单通道固件副本），用于物理实验中**同时测量电压 U 与电流 I**：

| 上位机模块 | 识别区 | 核心功能 |
|-----------|-------|---------|
| `ohm_sensor.py` | icon: R / 欧姆定律 | R = U/I：实时电阻 + 历史 R-t 曲线 + **I-U 曲线**（配合图表分析面板做线性拟合，斜率倒数即电阻 R，验证欧姆定律） |
| `power_sensor.py` | icon: P / 电功率 | P = U·I：实时功率 + P-t 曲线 + U/I-t 双曲线 + **梯形积分累计电能 W (J)** 与平均功率 |

两个模块共享同一套测量硬件：电压（三种方案任选）+ 电流（ACS712）。它们都支持：

- **测量模式**（连接控制卡下拉框）：`单板一体` / `双板分测` / `模拟器`
- **电压采样方式**（下拉框）：`ESP32 内置 ADC` / `ADS1115 (16位)` / `HX711 (24位)`
- 电流参数：ACS712 5A/20A/30A 量程、DC/AC（有效值，滚动 RMS）、**零点校准**（回路开路时点按钮取零点电压）
- 数据导出 CSV、采样频率 0.1~10 Hz 内联设置、亮/暗主题、双图表引擎（matplotlib / pyqtgraph）

## 1. 固件清单

### 一体固件（单板一体模式：一台 ESP32 同时采电压+电流）

| 固件 | 电压通道 | 电流通道 | 输出格式 |
|------|---------|---------|---------|
| `VI_ESP32_ADC.ino` | 内置 ADC，GPIO1，12 位 0~3.3V | ACS712 → GPIO2 | `时间戳,电压ADC,电流ADC` |
| `VI_ADS1115.ino` | ADS1115 16 位（I2C：SDA=21/SCL=22，可配 PGA/通道/速率） | ACS712 → GPIO2 | 同上（电压为有符号 16 位） |
| `VI_HX711.ino` | HX711 24 位（DOUT=4/SCK=5，通道 B 增益 32，AVDD=5V） | ACS712 → GPIO2 | 同上（电压为有符号 24 位） |

需要 [Adafruit ADS1X15](https://github.com/adafruit/Adafruit_ADS1X15) 库（仅 `VI_ADS1115.ino`）。

### 单通道固件（双板分测模式：电压板 + 电流板各一台）

以下 4 个文件是 `电压传感器/`、`电流传感器/` 目录下固件的**副本**（内容一致，加了两行来源注释），放进来方便本目录自成一体：

| 固件 | 来源 | 用途 |
|------|------|------|
| `V_ESP32_ADC.ino` | `电压传感器/ESP32_Voltage_Sensor.ino` | 电压板（内置 ADC，GPIO1） |
| `V_ADS1115.ino` | `电压传感器/ADS1115_Voltage.ino` | 电压板（ADS1115 16 位） |
| `V_HX711.ino` | `电压传感器/HX711_Voltage.ino` | 电压板（HX711 24 位） |
| `I_ACS712.ino` | `电流传感器/ESP32_ADC_Raw_Data.ino` | 电流板（ACS712 → GPIO1） |

> ⚠️ 它们是副本：改动请同步回原件（或改原件后重新复制），避免两处内容不一致。

## 2. 连接方式（单串口 + 电压/电流角色绑定）

每张「连接」卡只配置**一个串口**；这路数据到底是电压还是电流，由下方「电压参数」「电流参数」卡的**「当前连接」下拉**指定。可新建多个连接，分别作为电压源 / 电流源，搭配面板顶部的「双板分测」开关跨连接配对。

### 连接卡（每张）
| 控件 | 说明 |
|------|------|
| 连接方式 | 模拟器 / 串口 |
| 采样方式 | ESP32 内置 ADC / ADS1115 (16位) / HX711 (24位) —— 决定电压板固件；电流板固定用 `I_ACS712.ino` |
| 串口 | 唯一的串口选择（刷新/选择端口）；双板时每块板各用一张连接卡 |
| **固件开关** | **单板一体（VI_\*）**：同时输出电压+电流，该连接自出 U+I；**双板分测（V_\*/I_\*）**：单通道，角色由下方参数卡指定 |

### 面板顶部：双板分测开关
「＋添加连接」旁的全局开关。勾选后，把「电压设置」选中的连接与「电流设置」选中的连接两路 `时间戳,ADC` 流按**时间戳就近匹配（±50ms）**临时配对成 `(v_adc, i_adc)`，换算成 (U,I) 后用于功率 / 电阻计算。

### 角色绑定（参数卡「当前连接」）
| 电压参数「当前连接」 | 电流参数「当前连接」 | 双板分测 | 结果 |
|---------|---------|---------|------|
| 连接A | 连接A（单板一体 / 模拟器） | — | 一个连接自出 U+I → **有功率/电阻** |
| 连接A（V_\* 板） | 连接B（I_\* 板） | ✔ | 两路时间戳配对 → **有功率/电阻**（显示在电压源连接A行） |
| 连接A（V_\* 板） | 连接B（I_\* 板） | ✘ | 独立单通道：A 行只显 U、B 行只显 I → 无功率/电阻 |
| 未选中的连接 | — | — | 不采集数据（role=none） |

> 切换连接方式 / 双板分测后需点「连接」重新建立数据源。
> 双板分测打开时，数据流的先后配对由上位机 `TimestampPairer` 完成，两块板各自输出单值行即可，无需改固件。

## 3. 校准参数

**电压参数卡**（按「电压采样方式」自动启用对应项）：

| 参数 | 说明 | 默认 |
|------|------|------|
| 分压比 (R1+R2)/R2 | 实际被测电压 = ADC 端电压 × 分压比 | 1.0 |
| 放大倍数 | 有放大电路时填写，实际电压再 ÷ 倍数 | 1.0 |
| ADS1115 PGA 量程 | 6 档，必须与固件 `#define PGA_RANGE` 一致 | ±6.144V |
| HX711 AVDD / 通道 | 参考电压与增益；固件默认通道 B（增益 32） | 5.0V / B |

**电流参数卡（ACS712）**：

| 参数 | 说明 | 默认 |
|------|------|------|
| 量程 | 5A (185mV/A) / 20A (100mV/A) / 30A (66mV/A) | 5A |
| 供电电压 VCC | 未校准时零点电压自动跟随 VCC/2 | 5.0V |
| 零电流输出电压 | 零点校准时自动写入，可手动微调 | 2.5V |
| 电流分压比 | ACS712 输出 → ESP32 ADC 间分压的还原比 | 1.515 |
| 测量模式 | DC 直流 / AC 交流（滚动窗口有效值） | DC |
| 电流单位 | A / mA | A |

**零点校准**：回路断开（零电流）状态下点「零点校准」，取最近 10 个采样点的 ACS712 输出电压均值作为零点，消除温漂与 VCC 偏差；再次点击「取消零点」恢复 VCC/2。建议每次接线后做一次。

所有参数持久化在 `sensor_config.json` 的 `ohm_sensor` / `power_sensor` 键下（可在设置页导出/导入/清除）。

## 4. 上位机使用流程

1. `python main.py` → 侧边栏「欧姆定律」「电功率」（主页磁贴也可进入）
2. 连接控制卡：新建「连接」→ 选连接方式 → 选采样方式 → 刷新并选串口 → 在「电压参数」「电流参数」卡分别指定当前连接（单板一体选同一个；双板分测勾选面板顶部开关、电压/电流各选一块板）→ 连接
3. 开始采集：实时大数值（U/I/R 或 U/I/P/W）+ 逐行数据记录 + 统计
4. 图表：
   - 欧姆定律：子图① I-U 曲线（右侧分析面板选「线性拟合」，拟合方程斜率倒数 = R，看 R² 判断线性度）；子图② R-t 曲线
   - 电功率：子图① P-t 曲线；子图② U-t 与 I-t 双曲线；实时卡累计电能 W（焦耳，统计里同时换算 Wh）
5. 「保存数据」导出 CSV：
   - 欧姆：`时间(s),电压(V),电流(A),电阻(Ω)`（开路时电阻为 `-`）
   - 电功率：`时间(s),电压(V),电流(A),功率(W),累计电能(J)`（电能逐行梯形积分）

## 5. 常见问题

- **读数全为 0 / 电压为负**：检查分压比、放大倍数；HX711 通道选 B（增益 32）对应固件默认。
- **电流严重偏大/偏小**：做一次「零点校准」；确认量程与 ACS712 型号一致；电流分压比按实际电路填。
- **ADS1115 无数据（固件打印 `ERROR:ADS1115 not found`）**：检查 I2C 接线（SDA=21/SCL=22）与供电。
- **切换连接板块后需重新连接**：任一板块切换会自动断开当前连接（线程安全停止）。
- **模拟器模式下电能可能轻微为负**：模拟电流围绕零点波动是噪声，真实 DC 负载不会这样，属正常现象。
