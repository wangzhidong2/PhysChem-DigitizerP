# pH 传感器

SEN0161 pH 电极 + 放大模块，配 ESP32-S3 采集。上位机 `ph_sensor.py`（主类 `PhSensorWidget`，侧边栏图标 `pH`）把 ADC 原始值按校准曲线换算成 pH，支持单点/两点/三点校准。

详细模块介绍：[DFRobot SEN0161 pH 计 Wiki](https://wiki.dfrobot.com.cn/_SKU_SEN0161_pH_meter_pH%E8%AE%A1)

购买[参考（淘宝）](https://e.tb.cn/h.R19bhV92NZIwylY )搜索`PH值测试模块 电极 采集监测 土壤水质酸碱浓度传感器`https://e.tb.cn/h.R19bhV92NZIwylY 

## 1.接线

```
ESP32-S3           pH 放大模块
──────────         ──────────
5V           →     V
GND          →     G
GPIO1        →     PO（模拟输出）
GND          →     G（第二个接地，接地更稳）
```
```
电极  → 放大器圆形接口
```

- pH 放大模块要 5V 供电，接 3.3V 不工作
- PO 输出接 `ESP32-S3` 的 ADC 引脚 `GPIO1`（固件里就是 `ADC_PIN 1`）。PO 满量程约 0~5V（模块 5V 供电），超出 ESP32 ADC 的 3.3V 上限，得先降压再进 ADC：建议用 ADS1115 做 AD 转换，或者加分压电路。我用的是 `1:1` 分压，`300K:300K`
- 分压电路接法：

```
PO ─── R1 (300kΩ) ─┬── GPIO1
                   │
                 R2 (300kΩ)
                   │
                  GND
```

R1、R2 串联，从中点引一根线接 `ESP32-S3` 的 GPIO1：

`GPIO1 = PO × R2 / (R1 + R2) = PO / 2`

例：PO=5V → GPIO1=2.5V（在 ADC 量程内）；PO=0V → GPIO1=0V。固件读到的是分压后的电压，满量程对应 PO≈5V。

- pH 电极玻璃泡易碎，不用时泡在保存液 `3mol/L KCL(aq)` 里

## 3.固件与数据格式

固件：`ph esp32.ino`（ESP32-S3）

| 项 | 值 |
|----|-----|
| ADC 引脚 | GPIO1（`ADC_PIN 1`，ADC1_CH0） |
| 分辨率 | 12 位，`analogReadResolution(12)`，量化 0~4095 |
| 衰减 | 11 dB（`ADC_ATTEN_DB_11`），对应 0~3.3V |
| 采样间隔 | 100ms（`SAMPLE_INTERVAL 100`，10Hz） |
| 波特率 | 115200 |

串口输出（每行一条，CSV）：`时间戳(ms),ADC原始值`

```
示例
1234,2555
1334,2553
```

启动时先打印一段配置信息，最后一行 `START` 表示固件就绪。

固件输出的是分压后的 ADC 值（0~4095，对应 GPIO1 的 0~3.3V），上位机拿它直接参与 pH 换算，不再乘 2。所以校准点里的 ADC 值从固件读数抄就行，别手工换算成 PO 端电压。

## 4.校准

校准在程序里完成，参数写入 `sensor_config.json` 的 `ph_sensor` 键，重启自动加载。

### 4.1.三种模式

在「校准参数」卡点「✏️ 编辑校准参数」打开对话框，三种模式单选实时切换：

| 模式 | 拟合方式 | 需要的缓冲液 | 说明 |
|------|----------|--------------|------|
| 单点校准 | 理论斜率 + 偏移 | 1 个（任意 pH） | 还要填「理论斜率」（mV/pH，默认 −280，可改） |
| 两点校准 | 线性拟合 | 2 个（如 pH 4.00 + pH 9.18） | 适合大多数常规测量 |
| 三点校准 | 二次多项式拟合 | 3 个（如 pH 4.00 + 6.86 + 9.18） | 精度最高，适合精确实验 |

标准缓冲液参考：pH 4.00（邻苯二甲酸氢钾）、pH 6.86（混合磷酸盐）、pH 9.18（硼砂）。

### 4.2.单点校准的理论斜率

单点模式只测一个参考点，斜率由「理论斜率」参数提供。它指 SEN0161 放大板 PO 端口的等效斜率（已含板上增益）：

- 电极本身 25℃ 的 Nernst 斜率约 −59.16 mV/pH，但那是电极裸输出，没算放大幅度
- SEN0161 放大板 PO 端口的等效斜率约 −280 mV/pH（官方示例约 3.5 pH/V），程序默认值取的就是它
- pH 升高电压下降，所以是负值

换电极、电极老化或换了放大板后，实测斜率会偏离 −280，按实测值改（有两组数据可以反推斜率）。斜率填 0 是非法值：程序会记一条警告并临时改用默认值，得去「编辑校准参数」里修正。

### 4.3.校准步骤

1. 运行 `main.py`，进入 pH 传感器模块，连接串口
2. 开始采集，将清洗后的电极放入第一种缓冲液，等读数稳定，记下当前 ADC 值
3. 多点校准则依次测量其余缓冲液，分别记下 ADC 值
4. 点「✏️ 编辑校准参数」，选模式，填入各缓冲液的 pH 值和对应 ADC 值；单点模式还要填理论斜率（mV/pH）
5. 点确定后校准立即生效，参数写入 `sensor_config.json`；校准参数卡会显示当前生效的模式、各校准点与理论斜率

校准点默认值（出厂参考，务必按自己的电极重新标定）：

```python
default_calibration = [
    (4.00, 2555),
    (6.86, 2281),
    (9.18, 2030),
]
```

几条经验：

- 读数稳定再记录，电极刚浸入时漂移明显
- 每换一种缓冲液，先用去离子水冲洗电极并吸干，避免交叉污染
- 三点校准对缓冲液新鲜度最敏感，开封过久或受污染会直接拉低拟合质量

### 5.4.实时数据与统计

「实时数据」卡显示当前时刻的 `ADC` / `pH` 读数；下方统计栏有数据点、平均、最大、最小、标准差 σ，随采集实时更新。「清除数据」把曲线、记录与统计一并归零。

### 5.5.保存数据

点「保存数据」导出 CSV，文件名形如 `ph_sensor_data_YYYYmmdd_HHMMSS.csv`，存在运行目录（`main.py` 所在目录）：

```
time_s,adc_raw,ph_value
0.000,2555,4.00
0.100,2554,4.01
```

| 列 | 含义 |
|----|------|
| `time_s` | 相对开始采集的秒数（首点归零） |
| `adc_raw` | 固件上传的原始 ADC 值（0~4095） |
| `ph_value` | 按当前校准曲线换算出的 pH |

### 5.6.AI 分析实验

图表卡右上角「AI 分析实验」进对话式 AI，每轮提问自动附带当前数据与实验参数。本模块内置了一份专属系统提示词（能斯特方程、−280 mV/pH 等效斜率、三类校准拟合、电极老化的典型特征都在里面），在 AI 窗口「设置 → 模块预置系统提示词」可以查看和修改。端点 / Key / 模型按 OpenAI 兼容的 `/chat/completions` 格式配置，数据只发往你自己填的端点。详见根目录 [README.md 第 6.7 节](../../README.md)。

## 6.电极保养

- 首次使用：在 3mol/L KCl 溶液中浸泡 2 小时活化
- 短期保存：浸泡在保存液或 3mol/L KCl 溶液中
- 测量前后：用去离子水清洗，滤纸吸干，不要用力擦拭电极头（要不你试试，碎不碎我不管）

## 7.常见问题

**pH 值跳动大**
- 接线不牢、电源干扰
- 电极未完全浸没或未稳定
- 等待读数稳定后再记录

**测量值偏差大**
- 重新校准（建议三点校准）
- 单点校准的「理论斜率」与实际电极不符，按实测值修正
- 电极老化需更换

**ADC 值恒为 0 或 4095**
- 检查 VCC/GND/PO 接线
- 用万用表测 PO 电压（约 0~5V），再测 GPIO1 分压后的电压（应为 PO 的一半，约 0~2.5V）
- 电极开路或接触不良
- 外部电路干扰（实测在电解实验 pH 测不出来）

**改了校准参数但读数没变**
- 确认在对话框里点的是「确定」，取消不会写入
- 校准参数卡显示的是当前生效值；还不对就检查 `sensor_config.json` 的 `ph_sensor` 键
