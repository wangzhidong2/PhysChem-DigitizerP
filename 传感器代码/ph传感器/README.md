# pH 传感器

SEN0161 pH 电极 + 信号放大模块，ESP32-S3 采集。上位机模块 `ph_sensor.py`，支持单点 / 两点 / 三点校准，校准参数保存在 `sensor_config.json`。

详细模块介绍：[DFRobot SEN0161 pH 计 Wiki](https://wiki.dfrobot.com.cn/_SKU_SEN0161_pH_meter_pH%E8%AE%A1)

购买参考（淘宝）：https://e.tb.cn/h.R19bhV92NZIwylY 搜索「PH值测试模块 电极 采集监测 土壤水质酸碱浓度传感器」

## 1.接线

```
ESP32-S3           pH 放大模块
──────────         ──────────
5V           →     V
GND          →     G
GPIO1        →     PO（模拟输出）
GND          →     G（第二个地，接地更稳）
```

- pH 放大模块要 5V 供电，接 3.3V 不工作
- PO 输出接 ESP32-S3 的 ADC 引脚 GPIO1
- pH 电极玻璃泡易碎，不用时泡在保存液里

## 3.数据格式

固件 `ph esp32.ino` 串口输出：`时间戳(ms),ADC原始值`

```
1234,2555
1334,2553
```

- 波特率 115200
- 12 位 ADC，量程 0-4095（11dB 衰减，0-3.3V）
- 采样间隔 100ms（10Hz）
- 启动时输出 `START`

上位机按校准系数把 ADC 值换算为 pH 值。

## 4.校准

校准在程序内完成，参数写入 `sensor_config.json`，重启自动加载。

### 4.1.三种模式

| 模式 | 拟合方式 | 需要的缓冲液 |
|------|----------|--------------|
| 单点 | Nernst 理论斜率 + 偏移 | 1 个（任意 pH） |
| 两点 | 线性拟合 | 2 个（如 pH 4.00 + pH 9.18） |
| 三点 | 二次多项式拟合 | 3 个（如 pH 4.00 + 6.86 + 9.18） |

标准缓冲液参考：pH 4.00（邻苯二甲酸氢钾）、pH 6.86（混合磷酸盐）、pH 9.18（硼砂）。

### 4.2.步骤

1. 运行 `main.py`，进入 pH 传感器模块，连接串口
2. 开始采集，将清洗后的电极放入第一种缓冲液，等读数稳定，记下 ADC 值
3. 多点校准则依次测量其余缓冲液
4. 点击"编辑校准参数"，选择模式，填入各缓冲液的 pH 值和对应 ADC 值
5. 保存后校准立即生效，参数写入 `sensor_config.json`

默认参数：

```python
default_calibration = [
    (4.00, 2555),
    (6.86, 2281),
    (9.18, 2030),
]
```

## 5.使用步骤

1. 烧录固件，按上文接线
2. 运行 `main.py`，进入 pH 传感器模块
3. 连接串口，开始采集
4. 必要时先校准（见第 4 章）
5. 观察实时 pH 值与曲线，数据可存为 CSV

## 6.电极保养

- 首次使用：在 3mol/L KCl 溶液中浸泡 2 小时活化
- 短期保存：浸泡在保存液或 3mol/L KCl 溶液中
- 测量前后：用去离子水清洗，滤纸吸干，不要擦拭电极头

## 7.常见问题

**pH 值跳动大**
- 接线不牢、电源干扰
- 电极未完全浸没或未稳定
- 等待读数稳定后再记录

**测量值偏差大**
- 重新校准（建议三点校准）
- 电极老化需更换

**ADC 值恒为 0 或 4095**
- 检查 VCC/GND/PO 接线
- 用万用表测 PO 电压，应在 0-3.3V
- 电极开路或接触不良
