# HC-SR04 超声波模块

HC-SR04 超声波测距模块，上位机支持两个用途：位移测量（`ultrasonic_displacement.py`）和速度测量（`ultrasonic_velocity.py`）。两个模块共享本目录固件。

## 1.接线

根据固件选择对应的接线方式。

### 1.1.HC-SR04esp32.ino（ESP32）

```
ESP32            HC-SR04
─────────        ────────
5V (VIN)    →    VCC
GND         →    GND
GPIO5       →    TRIG
GPIO18      →    ECHO
```

### 1.2.HC-SR04esp8266.ino（ESP8266 / WeMOS D1）

```
ESP8266          HC-SR04
─────────        ────────
5V          →    VCC
GND         →    GND
D5 (GPIO14) →    TRIG
D6 (GPIO12) →    ECHO
```

### 1.3.csbwithbt.ino（ESP32-S3 + BLE）

```
ESP32-S3         HC-SR04
─────────        ────────
5V          →    VCC
GND         →    GND
GPIO5       →    TRIG
GPIO6       →    ECHO  （经 1kΩ 电阻分压后接入）
```

ECHO 输出高电平为 5V，直接接 3.3V GPIO 有损坏风险，接线时串联电阻或加分压保护。

## 3.数据格式

固件串口输出：`时间戳(us),回波时间(us)`

```
123456,1450
123476,1465
```

- 波特率 115200
- 启动时输出 `START`
- 触发间隔 20ms（约 50Hz 上限）
- 回波时间超时阈值 6ms

距离换算（上位机完成）：

```
距离 (cm) = 回波时间 (µs) / 58.0
```

## 4.上位机模块

| 文件 | 模块名 | 主类 |
|------|--------|------|
| `ultrasonic_displacement.py` | 超声波位移 | `UltrasonicWidget` |
| `ultrasonic_velocity.py` | 超声波速度 | `UltrasonicVelocityWidget` |

位移模块实时显示距离曲线；速度模块按连续两次回波时间差计算瞬时速度：

```
v = (t₀ - t₁)/2 × vₛ / [(t₁ + t₀)/2 + Δt]
```

- `t₀`/`t₁`：相邻两次回波时间 (µs)
- `Δt`：两次测量的时间间隔 (s)
- `vₛ`：声速 34000 cm/s

## 5.使用步骤

1. 烧录固件（Arduino IDE，波特率 115200）
2. 按上文接线
3. 运行 `main.py`，进入对应模块
4. 选择连接方式（有线串口 / 模拟器），连接串口
5. 开始采集，观察距离/速度曲线
6. 保存数据为 CSV

## 6.常见问题

**数据跳动大**
- 测量表面不平整或倾斜
- 电源不稳定
- 距离过近（<2cm）或过远（>400cm）超出量程

**无数据输出**
- 检查 VCC/GND/TRIG/ECHO 接线
- 确认波特率为 115200
- 用 Arduino 串口监视器确认固件有输出

**测量值整体偏大或偏小**
- 声速受温度影响（约 0.6 m/s/°C），实验环境温差大时可修正系数
- 也可先测一段已知距离，反推校准系数
