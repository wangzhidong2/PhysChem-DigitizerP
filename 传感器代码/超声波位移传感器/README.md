# HC-SR04 超声波模块

HC-SR04 超声波测距模块，上位机有两个用途：**位移测量**（`ultrasonic_displacement.py`，主类 `UltrasonicWidget`，图标 `x`）和**速度测量**（`ultrasonic_velocity.py`，主类 `UltrasonicVelocityWidget`，图标 `v`）。两个模块共享本目录的三套固件。

## 1.接线

按固件选对应的接法。

### 1.1.HC-SR04esp32.ino（ESP32）

```
ESP32            HC-SR04
─────────        ────────
5V (VIN)    →    VCC
GND         →    GND
GPIO5       →    TRIG
GPIO18      →    ECHO
```

固件里是 `TRIG_PIN 5` / `ECHO_PIN 18`，注释还留了 GPIO4/GPIO2、GPIO16/GPIO15 两个备选，改线记得同步改固件。

### 1.2.HC-SR04esp8266.ino（ESP8266 / WeMOS D1）

```
ESP8266          HC-SR04
─────────        ────────
5V          →    VCC
GND         →    GND
D5 (GPIO14) →    TRIG
D6 (GPIO12) →    ECHO
```

### 1.3.csbwithbt.ino（ESP32-S3 + BLE）

```
ESP32-S3         HC-SR04
─────────        ────────
5V          →    VCC
GND         →    GND
GPIO5       →    TRIG
GPIO6       →    ECHO  （经 1kΩ 电阻分压后接入）
```

- 这是唯一带 BLE 的固件。ESP32-S3 只支持 BLE（没有蓝牙经典 SPP），广播设备名为 `csbsenior`，走 Nordic UART Service（NUS，`6E400001-B5A3-F393-E0A9-E50E24DCCA9E`）
- 去掉了 `delay()` 阻塞以提高采样率，属于高频采集版

> ECHO 输出高电平为 5V，直接接 3.3V GPIO 有损坏风险，接线时串联电阻或加分压保护。不过，部分版本支持3.3V输出，**看清楚！**

## 3.固件与数据格式

| 固件 | 开发板 | TRIG / ECHO | 通信 |
|------|--------|-------------|------|
| `HC-SR04esp32.ino` | ESP32 | GPIO5 / GPIO18 | 串口 |
| `HC-SR04esp8266.ino` | ESP8266（WeMOS D1） | GPIO14(D5) / GPIO12(D6) | 串口 |
| `csbwithbt.ino` | ESP32-S3 | GPIO5 / GPIO6 | 串口 + BLE(NUS) |

三套固件都是：

- 输出 `时间戳(us),回波时间(us)`，波特率 115200，启动时输出 `START`
- 触发间隔下限 `MIN_INTERVAL 20000`（20ms，约 50Hz 上限）
- 回波超时 `ECHO_TIMEOUT 6000`（6000µs）

```
123456,1450
123476,1465
```

### 3.1.量程

单次回波最长只等 6000µs，对应可测距离上限约：

```
6000 µs ÷ 58 ≈ 103 cm
```

所以实际可用量程大约 2cm ~ 100cm，不是 HC-SR04 标称的 400cm。超时后固件不输出这一条，表现为数据"断流"。要测更远距离，把 `ECHO_TIMEOUT` 改大后重新烧录。

距离换算在上位机完成：

```
距离 (cm) = 回波时间 (µs) / 58.0
```

58 这个系数来自往返声速：340m/s 下 1cm 对应约 58µs（往返）。声速随温度变化约 +0.6 m/s 每 ℃（≈ +0.17%/℃），温差大的实验会有系统性偏差。

## 4.两个上位机模块

| 文件 | 模块名 | 主类 | 图标 |
|------|--------|------|------|
| `ultrasonic_displacement.py` | 超声波位移 | `UltrasonicWidget` | `x` |
| `ultrasonic_velocity.py` | 超声波速度 | `UltrasonicVelocityWidget` | `v` |

### 4.1.位移模块

实时显示回波时间（µs）、距离（cm）与相对时间；统计栏有数据点、平均、最大、最小（cm）；图表 y 轴按数据范围自适应。

### 4.2.速度模块

按连续两次回波时间差计算瞬时速度（回声定位差分法）：

```
v = (t₀ − t₁)/2 × vₛ / [(t₁ + t₀)/2 + Δt]
```

- `t₀`/`t₁`：相邻两次回波时间（µs）
- `Δt`：两次测量的时间间隔（s），取相邻时间戳之差（无数据时回退到固件的 20ms）
- `vₛ`：声速 34000 cm/s
- 结果单位 cm/s；统计栏给速度的数据点、平均、最大、最小

「采样窗口」控件（连接控制卡里的 SpinBox，5~100 点，默认 10）目前没有接进速度算法——速度始终按最近两点差分，改这个值不影响结果。

### 4.3.连接方式

两个模块的下拉框都只有**有线串口 / 模拟器**两项，不支持 BLE。就算烧了 `csbwithbt.ino`，也只能用 USB 串口读；BLE 那一路要配别的上位机（如 nRF Connect）才能看到数据。没装 pyserial 时自动切到模拟器模式。

### 4.4.采样频率

内联可编辑下拉框，预设 10 / 5 / 2 / 1 / 0.5 / 0.2 Hz，也可以手动输入 0.1~10 Hz。固件触发间隔 20ms（50Hz 上限），实测受回波耗时与串口带宽限制，上位机只做降频。

### 4.5.操作步骤

1. 烧录固件（Arduino IDE，波特率 115200）
2. 按上文接线
3. 运行 `main.py`，进入对应模块
4. 选择连接方式（有线串口 / 模拟器），连接串口
5. 开始采集，观察距离/速度曲线
6. 保存数据为 CSV

### 4.6.保存数据

两个模块都用「保存数据」导出 CSV，存在运行目录（`main.py` 所在目录），表头不同。

位移（`ultrasonic_data_YYYYmmdd_HHMMSS.csv`）：

```
timestamp_ms,distance_cm
0,25.862
21,25.914
```

表头写的是 `timestamp_ms`，值是相对开始采集的毫秒（首点归零），列名与单位一致，可以直接导入。

速度（`ultrasonic_velocity_data_YYYYmmdd_HHMMSS.csv`）：

```
time_s,distance_cm,velocity_cm_s
0.000,25.862,12.345
0.021,25.914,11.980
```

| 列 | 含义 |
|----|------|
| `time_s` | 相对开始采集的秒数（首点归零） |
| `distance_cm` | 由回波时间换算的距离 |
| `velocity_cm_s` | 差分法算出的瞬时速度 |

### 4.7.AI 分析实验

两个模块的图表卡右上角都有「AI 分析实验」，每轮提问自动附带当前数据与实验参数。模块内置了专属系统提示词（`距离=回波/58`、声速温度系数、量程边界与运动速度不匹配导致的混叠等），在 AI 窗口「设置 → 模块预置系统提示词」可以查看和修改。详见根目录 [README.md 第 6.7 节](../../README.md)。

提示词里把量程写成「约 2~100cm / 有效回波窗口 100~60000µs」，后者是笔误（固件超时是 6000µs），以第 3.1 节的固件实际值为准。

## 5.常见问题

**数据跳动大**
- 测量表面不平整或倾斜（超声波要有平整反射面）
- 电源不稳定
- 距离过近（<2cm）或过远（超出约 100cm 的上限，见 3.1）
- 附近有其他超声波源，或多个模块同时工作互相干扰

**无数据输出 / 数据中途断流**
- 检查 VCC/GND/TRIG/ECHO 接线
- 确认波特率为 115200
- 用 Arduino 串口监视器确认固件有输出
- 断流多半是超时：目标太远或反射太弱，超过 6000µs 固件就不发这一条

**测量值整体偏大或偏小**
- 声速受温度影响，实验环境温差大时可修正系数
- 也可先测一段已知距离，反推校准系数

**速度曲线噪声特别大**
- 差分法对回波时间的抖动非常敏感，相邻两点的微小误差会放大成速度尖峰
- 让被测物体运动平稳一些，或者先平滑距离数据再算速度

**BLE 连不上**
- 本模块上位机不支持 BLE，改用 USB 串口
- 确认烧的是 `csbwithbt.ino`，且广播名是 `csbsenior`

## 6.技术参数

| 参数 | 值 |
|------|-----|
| 测量原理 | 超声波回波测距 |
