# 力 / 质量传感器

HX711 24 位 ADC + 电阻应变式称重传感器，ESP32-S3 采集。上位机模块 `force_sensor.py`，支持去皮、两点校准、有线串口和 BLE 两种连接方式，校准参数保存在 `sensor_config.json`。

## 1.接线

### 1.1.ESP32-S3 ↔ HX711 模块

```
ESP32-S3          HX711
──────────        ──────────
3.3V        →     VCC
GND         →     GND
GPIO4       →     DT (DOUT)
GPIO5       →     SCK (PD_SCK)
```

### 1.2.HX711 ↔ 称重传感器

```
HX711             称重传感器
──────────        ──────────
E+           →    激励正极（红）
E-           →    激励负极（黑）
A+           →    通道A正极（绿，默认使用）
A-           →    通道A负极（白）
B+ / B-      →    未使用
```

不同厂家的称重传感器线序可能不同，以传感器标注为准。接线松动会导致读数跳动。

## 3.数据格式与命令

固件 `force.ino` 串口输出：`时间戳(ms),ADC原始值`

```
1234,-58720
1314,-58695
```

- 波特率 115200
- 24 位 ADC，通道 A（增益 128）
- 采样间隔 80ms（约 12.5Hz）
- 启动时输出 `START`

串口命令：

| 命令 | 作用 | 响应 |
|------|------|------|
| `TARE` | 去皮，清零当前负载 | `TARE_DONE,<offset>` |
| `CALIBRATE` | 进入校准提示 | `CALIBRATE_READY,place_known_weight` |

## 4.校准

校准在程序内完成，参数写入 `sensor_config.json`。

换算关系：`质量 = (当前ADC − offset) × scale`

### 4.1.步骤

1. 运行 `main.py`，进入力传感器模块，连接串口
2. **去皮**：空载时点"去皮（TARE）"，读数归零
3. **校准**：点"校准（CALIBRATE）"，空载记录零点，输入已知砝码质量，放上砝码记录加载值，程序自动算出 offset 和 scale 并保存

### 4.2.示例

空载 ADC −58720，放 100g 砝码后 ADC −52720：

- 差值 = 6000
- scale = 100 / 6000 = 0.016667
- offset = −58720

读数 −55720 时：质量 = (−55720 + 58720) × 0.016667 = 50.0g

## 5.使用步骤

1. 烧录固件，按上文接线
2. 运行 `main.py`，进入力传感器模块
3. 选择连接方式（有线串口 / BLE蓝牙 / 模拟器），连接
4. 先去皮，必要时校准
5. 开始采集，观察质量曲线；数据可存为 CSV

CSV 列：`time_s, raw_adc, force`

## 6.常见问题

**ADC 恒为 0**
- DT（GPIO4）/ SCK（GPIO5）接线错误或松动

**读数跳动大**
- 传感器接线松动
- 平台不稳或环境振动

**校准后不准确**
- 空载读数不稳定时不要校准
- 砝码太轻（建议 100g 以上）

**读数一直为负**
- 称重传感器 A+ / A- 接反，交换绿白两线

**BLE 连不上**
- 先在系统蓝牙设置里配对设备
- 确认已安装 `bleak` 库
