## 二、说明

该数字化实验采集系统是一套用于中学物理、化学实验的数据采集设备，由下位机和上位机两部分组成。下位机是烧录在 ESP32、ESP8266 等开发板中的固件，负责读取超声波、pH、力、电压、电流等传感器的信号，进行AD 转换，按“时间戳,数值”的格式将数据通过 USB 串口等方式发送出去。上位机是安装在电脑上的开源跨平台程序，也就是本手册说明的对象，负责接收数据、显示读数、分析实验以及导出数据文件。

传统实验数据大多记录孤立的时刻数值，误差大，变化稍快的过程无法准确描述。

市售同类数字化实验设备单个传感器往往超过二百元，且壁垒厚，大部分需要成套采购，动辄上万，对于中学是一笔不小的开支。本系统所用开源硬件，成本不足八十元，硬件固件，上位机源代码是自由软件，全部以 GPL-3.0 协议公开，学校可以按预算分批搭建，也可以自行维修和扩展。

本手册面向使用软件的教师、学生和实验室管理员，不要求读者具备编程基础。

（毕竟，都是手册了，我尽力说细）第一次使用时，建议先阅读第五章完成软件安装，再按第六章、第七章熟悉主页和通用采集流程，之后根据所做实验翻阅对应传感器章节。第十八章和第二十章分别介绍日志排障和常见问题，设备连接异常时可以直接查阅。固件烧录和接线属于软件之外的硬件准备工作，集中安排在第十九章。

软件提供模拟器模式，不接硬件也能产生模拟数据，因此没有实验所需硬件时同样可以先对照本手册熟悉全部界面操作。

AI 实验分析和浏览器仪表盘属于扩展功能，需要自行配置接口或安装可选插件，不使用时不影响常规采集。

## 三、功能特点

软件当前包含六个测量模块：超声波位移、超声波速度、pH、力、电压、电流。

模块以“万物皆插件”的理念设计，主程序启动时自动扫描“sensors”目录并加载，增加新的传感器，只需把固件和上位机文件放入对应目录，不必修改主程序，主页和导航栏会自动出现新模块的入口。（参考 Agents.md）。

设备连接支持两种方式。有线串口用 USB-C 线连接开发板，通信波特率固定为 115200；模拟器模式不使用硬件，由软件生成模拟数据，供演示使用。两种方式下界面操作完全一致，串口通信库 pyserial 未安装时，软件会自动隐藏不可用的方式并给出安装提示，不会中途退出。

采集界面以大号数字显示当前读数，下方实时给出数据点数、平均值、最大值、最小值和标准差，左侧数据记录区逐行写出每次读数的时间和数值，右侧曲线图随采集同步延伸。数据可以保存为 CSV 文件，用 Excel 或 WPS 直接打开。软件内置 pyqtgraph 和 matplotlib 两个绘图引擎，前者支持缩放、拖动和悬停读数，是默认引擎；后者出图简洁直观，适合导出作为报告插图。

引擎可在设置中随时切换，已经绘制完成的曲线会自动用新引擎重新绘制，不需要重新采集。

pyqtgraph 引擎下，图表左侧带有分析栏。横轴可以选择显示全部数据，或只显示最近 0.1 秒到 3 小时的滚动窗口；曲线拟合提供线性、二次、三次、对数、幂函数五种方式，拟合线以同色虚线叠在原图上，方程和决定系数 R² 标在图表左上角；遇到明显的干扰点，可以按残差剔除前百分之若干的数据点并多级撤销，剔除只影响显示和拟合，原始数据保持不变。

各传感器的校准方式按测量原理设计，校准过程并不完全相同。pH 用标准缓冲液做单点、两点或三点校准；力传感器先去皮，再用已知砝码做两点标定，读数可在克、千克、牛顿之间切换；电压可以扣掉基线零点，并在千伏、伏、毫伏之间换算；电流要在开路状态下校零，另可切换 5A、20A、30A 量程和直流、交流模式。详情参考各模块 README.md，校准结果统一存到程序目录下的 sensor_config.json，跨会话保存，重新打开软件不用二次校准。

采集结束后，可以点击图表卡上的“AI 分析实验”按钮，填写实验名称、目的和条件，用对话方式让大模型总结趋势、识别异常点、推荐拟合函数和分析误差来源。每轮提问会自动附上当前最新数据，每个模块还内置了结合该传感器测量原理的系统提示词。接口地址和密钥由使用者自行填写。软件还带一个可选的数据接口插件。开启后，同一局域网内的手机、平板或其他电脑用浏览器打开地址就能够查看实时仪表盘，在网页上直接连接、采集和去皮；同时开放 REST 接口和 MCP 代理，外部程序和 AI 工具也能读到数据。

上述插件独立，删掉插件目录不影响主程序运行。

## 五、软件的获取与启动

软件提供两种使用方式。建议不熟悉 Python 的使用者直接用预打包版本：在项目 Releases 页下载压缩包，解压到任意目录，双击主程序就能运行，机器上不用装 Python。

希望从源代码运行的使用者，先到 Python 官网安装 3.10 以上版本，执行 pip install -r requirements.txt 安装依赖。依赖中 PySide6 和 Fluent-Widgets 组件库提供图形界面，numpy 用于数值计算，pyserial、matplotlib、pyqtgraph、flask 均为可选项，缺失时对应功能自动降级。准备好后在项目根目录执行 python ./src/main.py 启动软件。要注意 sensor_config.json、app_config.json 和 logs.json 这几个配置文件都生成在 ./src/main.py 所在目录（即 ./src/ 目录）。更换目录会清空配置。

## 六、主页与模块导航


传感器模块卡片列出主程序扫描到的全部模块，每行显示模块图标、名称以及“物理实验模块”或“化学实验模块”的分类说明，右侧带“进入”按钮。安装了数据接口插件时，项目简介卡片下方还会出现一张“数据接口”卡片，可供 Flask 网页启动。

进入测量模块有两条路：点这张卡片里的“进入”，或者直接点左侧导航栏的模块图标，效果一样；想回主页，点导航栏最上方的主页图标。

模块由程序启动时自动扫描加载，主页不提供手工添加模块的入口。如果新增了传感器文件却没有出现在列表中，通常是因为文件头识别区的图标、名称或类名格式有误，控制台日志会给出加载失败的具体原因。

未安装 flask 时数据接口卡片不显示，这属于正常情况。

## 七、连接设备、开始一次采集

六个传感器模块的页面布局基本一致，下面这套连接和采集流程在每个模块上都适用。进入任一模块后，页面最上方是“连接控制”卡片，页面底部排列着“开始采集”“停止采集”“保存数据”“清除数据”四个按钮。



开始实验前，先用 USB 线把烧录好固件的开发板接到电脑。在连接方式下拉框中选择“有线串口”，点一下“刷新”，串口下拉框会列出当前可用的端口，选择开发板对应的端口后点“连接”。没有硬件时，把连接方式改成“模拟器”，串口选择会自动隐藏，点连接就进入模拟采集，界面上的数据和曲线都是软件生成的。连接成功后，“连接”按钮变成“断开”，实时数据区开始跳数，说明通信已经通了，但这时还没有真正开始记录曲线。

采样频率下拉框用来决定每秒记录多少个数据，例如力和 pH 常用 10 Hz。准备就绪后点“开始采集”，曲线图开始从左向右绘制，数据记录区逐行追加“时间、读数”的记录，统计信息随每个新数据刷新。实验过程中若部分模块发现零点有漂移，可以执行模块上的去皮或零点校准，已经画出的曲线会按新零点重新计算，不必重新采集。实验做完点“停止采集”，曲线停在最后一帧供分析；确认数据没问题，点“保存数据”选个位置，数据就存成了 CSV 文件。同一组实验想重新采集实验数据，点“清除数据”把曲线和记录清掉重来。

列表里找不到端口，先换 USB 口试，确认数据线不是只能充电的那种，再装上 CH340G 或 CP210x 驱动。串口框显示“未安装 pyserial”，是通信库没装，执行 pip install pyserial 后重启软件，等安装的这段时间可以先用模拟器模式熟悉界面。软件和下位机之间的波特率固定为 115200，这个数值写在固件和软件两边，界面上没有修改入口。

## 八、超声波位移测量

这个模块用的是常见的 HC-SR04 超声波测距头。模块发出一束超声波，碰到物体后反射回来，固件按声波往返的时间算出距离。位移测量直接把这个距离当作物体的位置，画成距离随时间变化的曲线，小车沿斜面下滑、自由落体这类过程都能用它记录。

图 3　超声波位移测量页面

接线时 TRIG 和 ECHO 两根信号线按固件默认接 GPIO5 和 GPIO18，改了线要同步改固件。模块固定在支架末端，探头正对运动物体，中间不能有书本、手臂之类的遮挡。另外有一个容易烧引脚的细节：不少 HC-SR04 的 ECHO 输出是 5V 电平，直接接到 3.3V 的 ESP32 上有风险，要按模块说明串联电阻分压。建议用2020 版本，支持 3.3V。

进入“超声波位移”模块、连上设备后，实时数据卡片一行给出当前时刻、回波时间（微秒）、距离（厘米）和相对计时，统计行写着平均、最大、最小距离。开始采集，横轴时间、纵轴距离的曲线就往前延伸。读数乱跳时，先看测量路径上有没有多余杂物，再检查模块固定得稳不稳；棉被、海绵这类松软材料会吸声，物体超出量程也会读到乱数。没有硬件时选模拟器，用来熟悉界面。

## 九、超声波速度测量

速度模块和位移模块用的是同一套 HC-SR04 硬件、同一套固件，不同的是上位机把相邻两次距离做差分，再除以时间间隔算出速度。因为测量量不同，它在导航栏里单独占一个模块，图标是“v”。

图 4　超声波速度测量页面，上方为距离曲线，下方为速度曲线

页面上比位移模块多一个“采样窗口”选项，单位是点。速度是相邻两次距离相减再除以时间得到的，距离上一点小抖动在相减后会被放大，所以要拿若干个点做平均。

参与平均的点越多，曲线越平滑，但速度真发生突变时反应也慢半拍；点数少则反应快，曲线毛刺多。看缓慢加速把窗口调大，记碰撞这种一瞬间的过程就把窗口调小，按实验现象取舍。

速度页面上下排列两幅图，上面仍是距离曲线，下面是速度曲线，实时数据行同时给出距离和速度。速度为正表示物体正在远离探头，为负表示正在接近探头。让小车朝探头方向运动再弹回，就能看到速度曲线越过零点改变符号的完整过程。

## 十、pH 值测量与校准

pH 模块配合 SEN0161 pH 电极和信号放大板使用，测量溶液酸碱度，常用于酸碱中和滴定、比较溶液 pH 等化学实验。放大板必须使用 5V 供电，接 3.3V 不工作；其输出 PO 最高约 5V，超出开发板 ADC 的 3.3V 上限，因此需要按说明加分压电路，或改用 ADS1115 转换模块（16 位 ADC，更准）。

pH 读数准不准，关键在校准。软件给了单点、两点、三点三种模式。只有一种标准缓冲液、又接受理论斜率时用单点；日常实验做两点，用两种缓冲液线性拟合就够了；要求高的实验做三点，分别取酸性（pH 4.00）、中性（pH 6.86）、碱性（pH 9.18）三种缓冲液，软件做二次拟合。校准的操作是：先连上设备，在“校准参数”卡片点“编辑校准参数”，弹窗里选好模式，把电极插进第一种缓冲液，等读数稳住后，把这瓶缓冲液的标称 pH 和当时的 ADC 值填进去，其余各点照此依次做完，最后点确定。

图 5　pH 模块及三种校准模式选择对话框

确定后，校准状态文字立刻变成“单点校准”“两点校准”或“三点校准”，读数按新的换算关系重算，参数同时写进配置文件，下次开机直接沿用。测量前电极先用纯水冲一下，再放进待测溶液，点开始采集就能看到 pH 随时间的变化。电极头上的玻璃泡又薄又脆，测量间隙和长期存放都要泡在 3 mol/L 氯化钾保存液里，干放会报废；弄碎了，那么恭喜你，换一个吧！

## 十一、力与质量测量

力模块由 HX711 二十四位模数转换板和应变片式称重传感器组成，可以测拉力、压力，也可以作为电子秤测质量，用于力学实验。HX711 的 DOUT、SCK 默认接 GPIO4、GPIO5，称重传感器的四根线按颜色接到 HX711 接线端子，具体线序以商家说明为准。接触不良时读数会一直跳，有条件最好把接点焊上。

应变片传感器的安装有方向要求：传感器一端用螺丝固定，另一端悬空承载，施力方向与标签箭头一致，白色覆胶部位不能直接按压，否则内部应变片会损坏。

图 6　力模块采集中，曲线为 matplotlib 引擎绘制

使用时先在“校准与去皮”卡片中选择显示单位：克、千克或牛顿，界面按 g = 9.8 m/s² 换算。秤盘空载静止时点“去皮（TARE）”，把秤盘自重置零；再把已知质量的砝码放在秤盘中央，点“校准（CALIBRATE）”，按提示输入砝码标准值，软件据此算出比例系数，状态变为绿色的“已校准”，并显示比例和偏移。取下砝码，放上被测物体或直接施力，就可以正式采集了。用一段时间发现零点漂了，空载再点一次去皮，之前画好的曲线按新零点重算。没做校准时界面只有原始 ADC 值并给出提示，这时的数字不能直接当成力来读。

## 十二、电压测量

电压模块支持三种硬件接法。最省事的是直接用 ESP32 内置 12 位 ADC，但 0.3V 以下和 3V 以上有一段非线性区，误差很大；HX711 是 24 位转换，分辨率高，缺点是量程小，只适合测毫伏级电压；ADS1115 是 16 位转换，走 I2C 接线，量程和精度比较均衡。按需选择。

图 7　电压模块页面，正在以模拟器模式采集

由于外加了分压或放大电路，软件必须知道电路参数才能把 ADC 原始值还原成实际电压。“ADC 与电路参数”卡片中的 ADC 位数要与烧录的固件方案一致；分压比按(R1+R2)/R2 的实际电阻填写；放大倍数按电路增益填写。每改动一项，右侧“实际量程”立刻重算，测量前先看一眼这个范围罩不罩得住待测电压。被测电压可能超过 3.3V 时一定加分压保护，不然烧 ADC。有时想把一个非零基线当零点扣掉，比如消除背景电动势，接上基线后点去皮，状态会从“未启用”变成已去皮。读数区把实际电压、ADC 端电压、原始 ADC 值三组数都列出来，对得上说明参数没填错，对不上就回头查分压比。

显示单位能在千伏、伏、毫伏之间切换。

## 十三、电流测量

电流模块使用 ACS712 霍尔电流传感器（由于霍尔效应，使用时远离磁场），有±5A、±20A、±30A 三种规格，对应灵敏度分别为 185mV/A、100mV/A、66mV/A。

与电压表不同，电流传感器必须串联进被测回路，电流从 IP+、IP- 两个引脚穿过，方向可以任意，接反只会改变读数正负。传感器零电流时输出约为供电电压的一半，5V 供电时约 2.5V，最高输出可达 4.5V，因此信号接入 3.3V 的 ADC 前同样要分压，默认分压比约 1.515。

图 8　电流模块页面

参数卡片里的量程要和实际买的模块对上，供电电压、分压比按电路填，卡片会跟着算出当前配置下能量程到多少。测直流之前先做零点校准：让回路保持开路，确认没有电流，再点零点校准，软件把这一刻的输出电压记成零点；每重新接一次线，最好都重做一遍，这个操作重复点也没关系。测交流电时把类型切到 AC，再设好 RMS 窗口点数，读到的就是窗口内的有效值。量程别贪大，实际电流只有几百毫安却选 30A 档，误差会大，按预计电流选最接近的一档。读数区除了电流，还有原始 ADC、ADC 端电压、传感器输出电压三列，接线有问题时顺着这三列从后往前查。

## 十四、图表分析

分析栏只在 pyqtgraph 引擎下出现。如果当前用的是 matplotlib，先到设置页把引擎换成 pyqtgraph，再回到模块页面，图表卡左侧就多出一栏分析工具。

图 9　电压传感器实时曲线

视图窗口部分决定横轴显示多长时间。选择“显示整个范围”时，从采集开始的所有数据都压缩在一幅图中；选择“滚动窗口”并填写时长后，画面只保留最近一段时间，（示波器模式）旧数据向左侧移出，适合长时间连续采集时只关注近期变化的场合，时长可填 0.1 秒到 3 小时。

曲线拟合给了线性、二次、三次、对数、幂函数五个选项。点一个，软件立刻算好拟合参数，用同色虚线把拟合曲线压在数据上，左上角写出方程和决定系数 R²。R²越接近 1，数据越贴近这个函数；反过来，R² 很难看就说明函数选错了或者数据本身不成这种关系。比如验证欧姆定律，对 I-U 数据做线性拟合，斜率就是电阻的倒数。

对数和幂函数只在正数范围有意义，定义域之外的数据点不参与计算。

曲线里混进了干扰造成的尖点，可以用离群点剔除处理：设一个百分比（默认 5%），软件在当前拟合结果里挑出残差最大的一批点丢掉，然后重新拟合并用散点把这些点标出来。剔错了点撤销，能一级一级往回退；“清除离散点”只负责清掉图上的散点标记，重新选一次拟合方式曲线就回来了。这些操作动的只是屏幕上的显示和拟合，原始数据一个都不改，导出的 CSV 依旧是完整数据。

## 十九、硬件连接与固件烧录

真实实验需要先把固件烧录进开发板，并完成传感器接线，这两步在软件之外完成，一次准备好后可长期使用。

烧录使用 Arduino IDE。安装后在“文件—首选项”的附加开发板管理器网址中填入 ESP32 或 ESP8266 的支持包地址，国内网络建议使用带 -cn 后缀的 ESP32 镜像；随后在开发板管理器中搜索安装 esp32 或 esp8266 支持包。用 USB 线连接开发板，在工具菜单选择板型：ESP32 选“ESP32 S3 Dev Module”，ESP8266 选“WeMos D1 R1”，并选好端口。打开传感器目录中对应的 `.ino` 文件上传。这里有一个 Arduino 的硬性要求：Sketch 目录名必须和 `.ino` 文件名一致——本仓库的固件都已放进与其同名的子目录（如 `./src/sensors/force/force/force.ino`），所以**可以直接在 IDE 里打开、上传，不必再新建 Sketch 粘贴代码**。

(其实IDE 会自动给你弹出一个对话框引导你)。

烧录完成后打开串口监视器，波特率设为 115200，复位开发板，正常情况下应先看到一行 START，随后持续输出“时间戳,数值”格式的数据，这表示固件运行正常，可以回到上位机连接使用。接线时按各传感器目录 README 中的接线图操作，重点确认供电电压和电平分压：5V 信号进入 3.3V 引脚前必须分压，pH 放大板必须 5V 供电。

## 二十、常见问题解答

问题一：串口下拉框里找不到开发板。

先换一个 USB 口并确认数据线支持数据传输，再安装 CH340G 或 CP210x 串口驱动，重新插拔后点“刷新”。仍找不到时运行项目目录中的 test_serial.py 进行诊断。

问题二：连接上了但没有数据，或数据完全不对。

打开 Arduino IDE 的串口监视器，波特率设成 115200。看不到 START 和数据行，是固件没烧进去，重新上传一遍。有数据但上位机读数误差很大，依次查波特率、接线、供电三项，同时让传感器远离电机这类干扰源
问题三：图表区域空白，提示“未检测到图表引擎”。

matplotlib 和 pyqtgraph 至少需要安装一个，执行 pip install matplotlib pyqtgraph 后重启软件。等待安装期间，数据采集和 CSV 保存可以正常进行。

问题四：模拟器数据和真实数据有什么区别。

模拟器不连接硬件，数值由软件生成，曲线、统计、拟合、保存都能正常使用，适合模拟演示；有线串口和蓝牙方式读到的才是传感器实测值。

问题五：校准结果是否可以迁移到另一台电脑。

校准参数存在程序目录的 sensor_config.json 里，把整个程序目录拷到新电脑，校准结果也会迁移；直接在新电脑运行，会生成一份默认配置，需要重新校准。

问题六：主页上没有数据接口卡片。

数据接口依赖 flask，装好该库（pip install flask）再重启软件，卡片就可以显示了。该插件可选，未安装时不影响主程序其他功能。

问题七：手机无法打开web仪表盘。

确认手机和电脑处于同一网络，复制的是“局域网”地址而不是 127.0.0.1 本机地址，“数据接口”和“局域网访问”两个开关均已打开，并检查电脑防火墙是否放行对应端口。
