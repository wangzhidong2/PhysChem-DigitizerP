# 多路 ESP32 连接 —— 设计文档（电压模块试点 → 全模块推广）

> 分支：`feat/multi-channel-voltage`
> 状态：**已推广至全部 6 个模块**（电压试点 + 电流 / 力 / pH / 超声波位移 / 超声波速度，见「推广实录」）

## 1. 背景与目标

原上位机每个模块只支持**一路**连接：单个串口线程、单组
`time_data / raw_data / voltage_data`、单条曲线。做「多点同时测量」类实验
（如同时测多个电压点、对比两路电源）时只能开两个模块页面，无法在同一张
图上直接对比。

目标：**连接控制**卡片支持「多路连接」——

1. 卡片内新增「＋ 新建连接」按钮，可添加任意多路；
2. 每一路可**单独选择**「有线串口 / 模拟器」；
3. 每一路有**独立的曲线颜色**（颜色下拉：预设色 + Fluent 取色对话框自定义）；
4. 每一路**单独连接 / 断开 / 删除**，互不影响；
5. 每一路有**独立的采样频率**与**独立的 ADC 换算参数**；
6. 多路数据以**主机统一时间戳**记录，叠加画在同一张图上；
7. 先在**电压模块**试点跑通全链路，再复制到其余 5 个模块。

## 2. 核心设计决策（与需求方对齐过的四项）

| 决策点 | 选择 | 理由 |
|---|---|---|
| 连接形态 | 同时连接多路并行采集 | 多点对比实验的核心诉求 |
| 图表形态 | 同一张图叠多条曲线 + 图例 | 量程相同便于直接对比；`ChartPanel` 多曲线能力现成 |
| 实施范围 | 先电压模块试点 | 避免设计返工 6 次；交互确认后再推广 |
| 时间基准 | 主机统一时间戳 | 各 ESP32 开机时刻不同，固件毫秒数不可跨路比较；主机打点天然对齐 |

## 3. 架构

### 3.1 数据模型 `_Channel`（纯 Python，不持 Qt 控件）

```
_Channel
 ├─ id / name        # 稳定 id（信号绑定），显示名（可自定义，留空回退默认名）
 ├─ color            # 曲线颜色（UI 下拉 ↔ 图表曲线共用）
 ├─ mode / port      # 'serial' | 'simulator'；串口名
 ├─ thread           # SerialThread / SimulatorThread（每路独立）
 ├─ sample_interval_ms   # 本路采样间隔（每路独立）
 ├─ adc_bits / divider_ratio / amp_ratio
 │   hx711_* / ads1115_* # 本路 ADC 换算参数（每路独立，见 3.7）
 ├─ visible          # 图表显示开关（图表卡勾选行控制，见 3.4）
 ├─ time_data / raw_data / voltage_data   # 每路独立的数据序列
 ├─ live_window      # deque(maxlen=10) 去皮/实时显示窗口
 ├─ last_sample_s    # 采样间隔过滤用的上次记录时刻（每路独立）
 └─ tare_offset_v / tare_active           # 每路独立去皮零点
```

要点：
- **id 不复用**：删除通道后其 id 永久废弃，避免 Qt 信号 lambda 捕获旧
  通道对象造成的数据串线；
- **UI 子卡控件**由模块统一保管在 `_rows[channel.id]`，数据模型与控件分离，
  `api_snapshot()` 读数据不触碰任何 Qt 方法（DataService 线程安全约定）。

### 3.2 UI：连接控制卡片

```
┌ 连接控制 ────────────────────────────── [＋ 新建连接] ┐
│ 每路连接可单独选择串口/模拟器与曲线颜色，多路同图叠加对比   │
│ ┌ 通道1 ──────────────────── [名称输入▾][颜色▾][🗑] ┐ │
│ │ 连接方式 [有线串口▾] 串口 [COM3▾] [刷新]            │ │
│ │ 采样频率 [10 Hz▾]                          [连接]   │ │
│ └──────────────────────────────────────────────────┘ │
│ ┌ 通道2 ──────────────────── [名称输入▾][颜色▾][🗑] ┐ │
│ │ 连接方式 [模拟器▾]   采样频率 [5 Hz▾]     [断开]    │ │
│ └──────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

- 每路一张 `FluentCard` 子卡（样式参考电学综合旧模块沉淀的多连接
  单元卡范式）：**header** = 名称编辑（留空恢复「通道N」）/ 图线颜色
  下拉（8 预设色 + 「自定义…」弹 `qfluentwidgets.ColorDialog`，
  带圆形色块预览图标）/ 删除按钮（`ToolButton` + `FluentIcon.DELETE`）；
  **body** 单行 = 连接方式 + 串口 + 刷新 + 采样频率 + 连接按钮；
- 「＋ 新建连接」在主卡 header 右侧（`FluentCard.add_header_widget`）；
- 模拟器模式下隐藏本路的串口标签/下拉与刷新按钮；
- 「删除」在仅剩一路时禁用（至少保留一路）；
- 主卡高度随子卡折叠/展开自适应（子卡折叠后 `sizeHint()` 不缩，
  按子卡实际 `height()` 重算，动画期间逐帧同步）；
- 通道子卡随配置持久化（`sensor_config.json` 的 `channels` 列表），
  重启后自动恢复。

### 3.3 数据流与线程

```
SerialThread(COM3) ─┐
SerialThread(COM5) ─┼─ data_received(str) ─→ handle_data(data, ch)
SimulatorThread   ──┘                          │
        每路线程一个，lambda 默认参数绑定通道对象
```

`handle_data(data, ch)` 的多路约定：
- `ERROR:` / `START` 按通道处理，设备出错只断开**这一路**；
- 记录用**主机时间戳**：采集期首个到达样本（任意通道）定为 t=0
  （`time.monotonic()`，存模块级 `_t0_mono`），此后每路每个样本的
  横轴 = 收到时刻 − `_t0_mono`。**不再使用固件时间戳做记录**
  （它只用于 CSV 行格式解析）；
- 采样间隔过滤按**主机接收时刻**、每路以**本路的 `sample_interval_ms`**
  独立过滤（原来按固件毫秒差 + 全局共用间隔）；
- 实时显示只更新**本路的实时行**（见 3.2.1），数据记录每行含通道名。

#### 3.2.1 实时数据卡：每路一行同屏

原实现三块共享标签（大字电压 / 原始ADC / ADC端电压）被多路数据
轮流覆盖（抢位置）。现改为：

- 每路一行（`_live_rows[ch.id]`）：通道名 + 大字电压（20px，
  **颜色 = 通道色**，多路一眼可辨） + 原始ADC + ADC端电压，
  通道增删时动态增删行；断开单路只复位该路行，其余路保留；
- 顶部**不再有共享汇总位**（实测多路时单一汇总标签仍被各路数据
  轮流抢占，已删）：`current_voltage_label` 转为**隐藏控件**
  （`setParent(self)` + `hide()`，不加入可见布局），内容 = 最新
  活动一路「名称: 值」，仅供全屏浮动面板折叠态摘要读取
  （`FloatingDataPanel._update_summary` 依赖标签控件的 `.text()`，
  不 reparent 也不要求可见，故隐藏即可）。

### 3.4 图表

- 图表卡内容顶部有**通道显示勾选行**：每路一个 `CheckBox`
  （文案 = 通道名），勾选控制该路曲线是否画入图表——只影响显示，
  采集/统计/保存不受影响；`visible` 字段随配置持久化，
  通道增删/改名时重建勾选行；
- `update_chart()` 只画**有数据且勾选**的通道，各画一条
  `c.plot(..., color=ch.color, label=ch.name)`，共用横轴；
  x 范围取**可见通道**时间并集；有数据但全部取消勾选时清空图表；
- 图表分析面板（拟合/离群点剔除）作用于**第一条可见曲线**
  ——pyqtgraph 侧沿用「第一曲线为拟合对象」的既有约定；
- 引擎切换（matplotlib/pyqtgraph）自动重放最近一次事务，多曲线同样适用。

### 3.5 去皮（每路独立零点）

`tare_now()` 对**所有有数据流入的通道**分别取最近 10 个采样的均值作为
各自的零点；状态标签逐路显示。`adc_to_voltage(raw, channel=ch)` 按通道
**自己的 ADC 参数换算、自己的零点扣减**。多路时这是物理上必要的：
不同 ESP32/电路的空载偏移不同。

### 3.6 CSV 保存（长表格式）

```
channel,timestamp_s,raw_adc,voltage_v
通道1,0.000,123,0.0992
通道2,0.103,-45,-0.0363
```

多路时间轴天然对齐（主机时间戳），Excel 透视/筛选按 `channel` 列分组
即可分析；旧版单通道文件是三列宽表，**格式不兼容**（多路时代用长表，
单路场景同样适用，不再分支维护两种格式）。

### 3.7 ADC 与电路参数（每路独立）

「ADC 与电路参数」卡片 header 新增**「当前连接」下拉**：切换后卡片
内全部控件（ADC 位数 / HX711 三参 / ADS1115 三参 / 分压比 / 放大倍数）
显示并编辑**所选路**的参数——交互范式与电学综合旧模块的
「电压/电流参数卡按当前连接独立配置」一致。

- 换算链路 `adc_to_voltage / adc_to_vadc` 的参数源优先级：
  **显式通道 > ADC 卡当前选中路 > 第 1 路 > 模块级默认**；
  `handle_data` / 去皮 / 数据重算均显式传本路通道；
- **模块级镜像**：`self.adc_bits` 等顶层字段始终与第 1 路保持镜像
  （第 1 路改动时同步），供旧版单通道调用方与顶层配置字段使用；
- 新建通道的 ADC 参数缺省继承**当前选中路**（复制一套再改）；
- 配置持久化：`channels` 每项记录全套 ADC 参数；顶层字段取第 1 路；
  旧版顶层配置自动迁移为第 1 路初值，旧版多通道配置缺字段用顶层值补齐；
- 模拟器量程按**本路位数**生成；`_ai_data` 的电路参数按主分析通道
  的参数描述。

## 4. 兼容性

| 接口 | 处理方式 |
|---|---|
| `DataService.connection_info / _apply_connection`（网页端连接管理） | 模块仍暴露 `mode_combo / port_combo` 属性，**指向第 1 路**的行控件；`set_connection('模拟器'/端口)` 作用于第 1 路，`connect=true` 连接全部、断开连接全部 |
| 网页端单曲线图表 | `api_snapshot().points` 仍是**主通道**（数据最多的一路）序列，前端零改动可继续画；新增 `channels` 字段（每路 name/color/connected/points_n/latest_raw）供后续前端做多曲线 |
| MCP 工具 | 同上，`get_snapshot` 可读到 `channels` 明细 |
| 旧版配置迁移 | 无 `channels` 键的旧 `sensor_config.json` 自动迁移为一路通道，顶层 `tare_offset_v / tare_active / sample_interval_ms / ADC 参数` 迁入该通道；保存时仍写顶层字段（取第 1 路）供旧版回退。旧版多通道配置缺 ADC 字段时用顶层值补齐 |
| `refresh_ports` / `disconnect_all` / `connect_device` | 方法名保留：刷新全部通道端口列表 / 断开全部 / 连接全部（通用动作表与退出清理不破） |

## 4.1 推广实录（其余 5 个模块）

试点架构（`_Channel` 数据模型 / 连接子卡 / 主机时间戳 / 每路一行实时明细 /
图表勾选行 / 兼容别名）**原样复制**，各模块按物理特性差异化：

| 模块 | 按路独立的参数 | 模块级共享 | 模块特有处理 |
|---|---|---|---|
| 电流 `current_sensor` | ACS712 量程 / VCC / 零点电压 / 分压比 / ADC 位数 / 零点校准（「ACS712 参数」卡 header「当前连接」下拉切换编辑） | DC/AC 模式、A/mA 单位、AC RMS 窗口 | AC 参考线仅单路可见时画（多路各路 RMS 不同）；去皮对全部有数据流入的通道分别校零 |
| 力 `force_sensor` | 去皮 offset / 标定 scale / calibrated（「校准与去皮」卡 header「当前连接」下拉；校准流程作用于所选路，换路即复位流程） | g/kg/N 单位、砝码默认值 | `tare_now` 对各路分别取零点并**逐路**向真串口发 TARE；`TARE_DONE,offset` 只覆盖发出那一路；校准取值用 `live_window`（修复旧版未采集时 `raw_data` 无限增长） |
| pH `ph_sensor` | 校准点 / 拟合系数 / 理论斜率（「校准参数」卡 header「当前连接」下拉；编辑对话框作用于所选路） | — | `_calc_coeffs_for(ch)` 按路重建单点/两点/三点拟合；`adc_to_ph` 按路系数换算 |
| 超声波位移 `ultrasonic_displacement` | —（无换算参数卡） | — | 单通道固件，多路 = 多个 ESP32；新增 `channels` 配置持久化（旧版无配置文件，自动建一路）；回波 100~60000µs 过滤保留 |
| 超声波速度 `ultrasonic_velocity` | —（无换算参数卡） | 采样窗口（点数） | 双子图（距离/速度）各自多曲线 + 各自图例；差分速度按**该路**相邻回波计算；新增 `channels` 配置持久化 |

推广后各模块统一获得：每路连接子卡（名称/颜色/模式/串口/采样频率/连接）、
每路一行实时明细（大字 = 通道色）、图表通道勾选行、CSV 长表（`channel` 列 +
主机时间戳）、`api_snapshot().channels` 明细、配置持久化与旧版单通道配置迁移。

## 5. 已知限制（试点的边界）

1. **AI 分析只喂主通道序列**：`_ai_data()` 取数据最多的一路作 points，
   其余路的概况写入 params 文字。多路全量喂给模型需要 ChartPanel 的
   AI 数据协议升级（points 结构目前是单序列 `[(t, y), ...]`）；
2. **拟合/离群点剔除只作用于第一条曲线**（见 3.4）；
3. **串口端口可重复选择**：两路选同一个 COM 口会被第二路打开失败
   （pyserial 独占），报错走该路的 ERROR 弹窗。后续可在 UI 上做去重
   提示；
4. **颜色为十六进制字符串**存配置，无命名/透明度支持；
5. **模拟器线程的发送频率在连接时定格**：连接中途改本路采样频率，
   过滤间隔即时生效，但模拟器发数周期要重连后才按新频率运行
   （真实串口不受影响，固件按自己的周期发）。

## 6. 验证记录

### 电压试点

- `py_compile` 通过；残留属性引用清零；
- offscreen 冒烟：默认建 1 路 → 新建第 2 路 → 双模拟器并行采集
  （各 14+ 点、主机时间轴共享）→ 图表 `spec` 出现两条曲线且颜色
  与色块一致 → 去皮两路独立零点 → CSV 长表落盘 → `api_snapshot`
  含 `channels` 明细 → 单路断开不影响另一路 → `disconnect_all`
  全断 → DataService `set_connection` 兼容路径正常。
- 纯逻辑走查（伪 Qt 桩、无 PySide6 环境）：`_Channel` 参数继承、
  `_adc_param_source` 四级优先级（显式通道 > 当前选中路 > 第 1 路 >
  模块级）、`adc_to_vadc` 按路换算（12 位满码 +3.3V / ADS1115
  满码 ±4.096V / 两路参数互不影响）9 项全过；
- `pyflakes` 无未定义名。

### 全模块推广

- 全部 6 个模块 `py_compile` 通过；
- 残留引用清零：旧单通道字段/方法（`serial_thread` /
  `last_sample_time_ms` / `start_timestamp_ms` / `sim_panel` /
  `on_mode_changed` / `connect_simulator` 等）在 5 个改造模块中
  grep 零命中；AGENTS.md 硬性禁令（`print` / 原生 Qt 控件 /
  直接 `import serial`）检查干净；
- 伪 Qt 桩纯逻辑走查 **74 项全过**（每模块约 15 项）：
  - 通用链路：默认建 1 路（缺 pyserial 自动模拟器）→ 新建/删除通道 →
    兼容别名存在 → 双路并行采集（各 10+ 点、首样本 t=0、双路时间轴
    对齐）→ 图表两条曲线（颜色 = 通道色、图例含通道名）→ 单路断开
    隔离 → `api_snapshot` 含 `channels` 明细 → CSV 长表落盘（通道行数
    与数据一致）→ 配置持久化 round-trip（路数/颜色/参数恢复）→
    `connect_device` / `disconnect_all` / `refresh_ports` 兼容入口；
  - 模块特有：电流逐路去皮归零且零点独立；力两路 offset 独立、
    `TARE_DONE` 只覆盖发出路、按路 scale 换算克值；pH 两路校准独立
    （同一 ADC → 不同 pH）、ADC 越界过滤；超声波回波窗口过滤、
    差分速度公式数值核对、双子图各两条曲线。
